# CH01 리디자인 V2 알려진 경계와 미검증 항목

## 의도된 임시 자산

- 음향은 외부 음원을 쓰지 않고 런타임에서 합성하는 의미 기반 임시 큐다. 빗소리, 바퀴, 쇠사슬, 잠금, 검, 등불, 물잔, 종이, 활의 사건 구분은 되지만 상용 BGM·폴리·보이스 품질은 아니다.
- S00~S06 핵심 화면은 신규 리디자인 아트를 사용한다. S07~S09의 일부 배경은 기존 KF 자산을 fallback/reference로 계속 사용한다.
- 108검의 정확한 `12×9` 슬롯은 전개 중 절차적 먹선 흔적으로 검증된다. 최종 CG는 모든 검을 개별 계수시키는 QA 화면이 아니라 생포/길 개방 결과 구도를 보여 준다.

## 자동 검증으로 대체하지 않은 것

- 실제 사람 E4 재미·감정·대사 호흡 평가: `NOT_RUN`
- 실제 물리 게임패드 완주: `NOT_RUN`
- 다른 GPU, 최소 사양 PC, 장시간 soak: `NOT_RUN`
- 상용 음향 믹스와 헤드폰/스피커별 청감: `NOT_RUN`
- CH02 이후 연결 장면의 신규 최종 아트: `OUT_OF_SCOPE`

## 판정 경계

- Godot 4.6.3 자동 회귀, 18개 전체 경로, 실제 Forward+ 렌더 캡처, Windows export smoke는 통과했다.
- 위 결과는 치명 오류와 데이터·화면 계약을 검증한다. `재미있음`, `출시 가능`, 최종 `KEEP`은 사람 플레이테스트 전까지 주장하지 않는다.
