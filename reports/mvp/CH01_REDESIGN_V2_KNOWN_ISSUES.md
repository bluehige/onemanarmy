# CH01 V5 알려진 경계와 미검증 항목

## 그래픽·연출 경계

- V5 런타임 미술은 인물이 박히지 않은 clean background 7장, 재사용 알파 plate 18장, 신규 Hero CG 2장으로 구성된다. 배경·인물·군중·전경을 별도 레이어로 합성하지만 Live2D, 골격 애니메이션, 입 모양 동기화는 범위 밖이다.
- S00 `강진오의 마지막 귀환`과 S02 `조문탁의 계약 이양`은 신규 V5 Hero CG다. S05 구검 완성과 S09 북문 봉쇄 확인은 이미 결정적 사건 이미지로 기능하는 V2 CG를 짧은 Hero beat로만 유지한다. S07의 세 이미지는 Hero CG가 아니라 분기 결과 확인용 still이다.
- 인물 포즈와 표정 변형은 제한적이다. 입장·퇴장·화자 전환·결정 순간에만 레이어 이동을 사용하며, 일반 대사 중 상시 호흡 애니메이션은 없다.
- S07~S08 결과 still과 일부 rollback fallback은 `assets/art/ch01-redesign-v2` 자산을 유지한다. 이 자산은 반복 대화 배경으로 사용하지 않는다.

## 검진·오디오 경계

- 108검은 하나의 배치 렌더러에서 `12조 × 9검`으로 구동한다. 다섯 단계 동작, 12개의 풀링된 조별 궤적, 국소 충돌·먼지·종이 효과를 사용하지만, 108자루 각각의 독립 궤적이나 물리 시뮬레이션은 아니다.
- 검 궤적 강도, 번섬 줄이기, 동작 줄이기는 실제 출력에 적용되지만, 이는 접근성 옵션이지 수동 전투 난이도 설정이 아니다.
- 음향은 외부 음원을 쓰지 않고 런타임에서 합성하는 의미 기반 임시 큐다. 빗소리, 바퀴, 쇠사슬, 잠금, 검, 등불, 물잔, 종이, 활의 사건 구분은 되지만 상용 BGM·폴리·보이스 품질은 아니다.

## PC/Web 표시 계약과 예외

- Windows와 데스크톱 Web은 같은 Noto Sans KR 폰트, 한국어 문구, 샷 데이터, 미술, UI 스크립트, `1920×1080` 논리 캔버스를 공유한다.
- 작은 Windows/Web 가로 화면에서 공통 구성을 그대로 1920×1080에 축소하면 터치 표적이 44px보다 작아진다. 이 경우에만 두 런타임 모두 같은 UI·폰트·자산을 `1280×720` 논리 밀도로 렌더링한다. 별도 모바일 게임플레이 UI 분기는 아니다.
- 세로형 Web은 게임을 과도하게 축소하지 않고 가로 회전 안내로 차단한다. 세로 플레이 지원은 범위 밖이다.
- Godot Forward+와 WebGL 2 Compatibility의 샘플링·색·선 렌더링은 GPU와 브라우저에 따라 소폭 다를 수 있다. 표시 계약은 동일 자산·레이아웃·줄바꿈을 우선하며 모든 GPU의 픽셀 단위 동일성을 주장하지 않는다.

## 자동 검증으로 대체하지 않은 것

- 실제 사람 E4 재미·감정·대사 호흡 평가: `NOT_RUN`
- 최종 제품 판정: `PENDING_E4`
- 실제 물리 게임패드 완주: `NOT_RUN`
- 다른 GPU, 최소 사양 PC, 장시간 soak: `NOT_RUN`
- 상용 음향 믹스와 헤드폰/스피커별 청감: `NOT_RUN`
- CH02 이후 연결 장면의 신규 최종 아트: `OUT_OF_SCOPE`

## 판정 경계

- 자동 회귀, 18개 전체 경로, 레이어 카탈로그, 9/108검 수량·중복, 다섯 단계·12 궤적 상태, PC/Web UI 계약은 자동 검증 대상이다.
- 위 결과는 치명 오류와 데이터·화면 계약을 검증한다. `재미있음`, `출시 가능`, 최종 `KEEP`은 사람 플레이테스트 전까지 주장하지 않는다.
