# CH01 V5 레이어드 VN 사람 플레이테스트 가이드

## 고정 대상

- Windows ZIP: `build/windows/onemanarmy-ch01-redesign-v2.zip`
- 실행 파일: `onemanarmy_ch01_redesign_v2.exe`
- 무결성: ZIP 옆 `.sha256` 또는 `BUILD_MANIFEST_CH01_REDESIGN_V2.json`과 대조
- 엔진: Godot 4.6.3, Windows x86_64
- Web: 같은 소스 후보의 GitHub Pages 빌드

Windows ZIP은 새 빈 폴더에 풀고 실행한다. 기존 개발 폴더의 저장 파일이나 PCK를 섞지 않는다. PC/Web 비교는 가능하면 같은 저장 상태와 같은 대사 ID에서 진행한다.

## 최소 세션

1. `처음부터`를 선택해 오프닝 네 문장을 끝까지 읽는다. 천류문 설명 없이 백팔 자루의 검, 끝내는 계약, 검의 이름, 죽은 동료·가족이라는 소문이 자연스럽게 이어지는지 확인한다.
2. S00에서 배경, 피난민·기병 plate, 이연, 검관이 서로 분리된 샷으로 읽히는지 보고 `지휘관을 묶는다`를 선택한다.
3. 다음 회차에는 S00에서 `길을 먼저 연다`를 선택한다. 두 분기 모두 108검이 `예비 → 곡선 비행 → 가속 → 충돌/잠금 → 잔향` 다섯 단계로 집행되는지 본다.
4. S02의 질문 세 가지를 회차별로 바꿔 보고, 조문탁이 원본 장부를 넘기는 결정적 순간에만 Hero CG가 등장하는지 확인한다.
5. S05 객잔에서 아홉 검이 서로 다른 역할을 하고, S06의 `추적 / 수호 / 봉쇄`를 각각 한 번 이상 끝낸다.
6. S09에서 네 번째 종, 북문 한 뼘 봉쇄, 측문 피난민 통과, 봉인 마차 개별 검문, 원본 장부 접수, 강진오 기록 정정이 시간순으로 끝나는지 본다. 마지막은 마차 `11대 대기 + 1대 이탈`로 읽혀야 한다.
7. 마우스와 키보드로 포커스, 누르기, 당기기, 검 회수를 수행하고, 가능하면 같은 세션 하나를 실제 게임패드로 완주한다.
8. 검 궤적 강도, 번섬 줄이기, 동작 줄이기 설정을 바꿔 실제 검진·국소 충돌 표현이 바뀌는지 본다.
9. Full, Summary, Result, 시네마틱 Skip이 같은 최종 상태와 결과를 남기는지 확인한다.

## PC/Web 비교

- Windows와 데스크톱 Web에서 같은 한국어 폰트, 줄바꿈, 대화창, 선택지, 레이어 배치가 유지되는지 비교한다.
- Web `1280×720`은 공통 `1920×1080` 논리 캔버스를 축소한 표준 비교 화면이다.
- Windows/Web `844×390` 가로 화면은 모두 `1280×720` 논리 밀도로 전환된다. 진행, 선택, `더보기`, 유틸리티, 인터랙션의 누를 수 있는 높이가 물리 44px 이상인지 확인한다.
- Web `393×659` 세로 화면은 축소된 게임 대신 `휴대폰을 가로로 돌려주세요`를 보여야 한다.

## 관찰 질문

- 오프닝 네 문장이 설명을 주면서도 천류문과 검의 진실을 더 알고 싶게 만드는가?
- S02가 끝날 때 `강진오`, 죽은 천류문 108명, 조문탁의 위조, 정정 원본, 기록고 방화용 봉인 마차, 네 번째 종의 관계를 이해했는가?
- S00 두 선택이 선악이 아니라 서로 다른 대가로 느껴졌는가?
- 이연의 대사가 절제되어 있으면서도 비장하고 기억에 남았는가?
- 배경과 인물이 분리된 샷이 단순 이미지 교체가 아니라 인물의 입장·퇴장·화자 전환으로 느껴졌는가?
- 이기어검의 다섯 단계, 12개 검진 궤적, 국소 충돌 효과가 단순히 검 이미지를 옮긴 것이 아니라 계약 집행으로 읽히는가?
- Hero CG가 대화 배경으로 남지 않고 강진오의 마지막 귀환, 조문탁의 계약 이양, 객잔 구검 완성, 북문 봉쇄 성립의 짧은 결정적 순간으로만 남는가?
- 어느 구간에서 지루함, 반복감, 대사 과잉, 화면 가림이 생겼는가?
- 세 결말 카드의 `다친 사람 / 놓친 정보 / 공개된 이름`이 선택의 빚으로 남았는가?
- CH01의 약속은 완수되면서도 이탈한 봉인 마차 한 대가 다음 장의 갈등으로 궁금해졌는가?
