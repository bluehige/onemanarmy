# CH01 E4 사람 플레이테스트 패키지

## 상태

- 판정: `NOT_RUN`
- 이유: E4는 실제 플레이어 관찰과 답변이 필요한 사람 평가다. 자동화 결과로 대체하지 않는다.
- 고정 대상: `build/windows/onemanarmy-ch01-mvp.zip`
- 무결성 확인: 같은 폴더의 `BUILD_MANIFEST.json`에 기록된 ZIP SHA-256과 대조한다.

## 준비

1. ZIP을 새 빈 폴더에 푼다.
2. `onemanarmy_ch01.exe`를 실행한다.
3. 처음 실행에서는 `처음부터`를 선택한다.
4. 화면이 잘리면 Windows 배율과 해상도를 기록하되 임의로 UI를 수정하지 않는다.
5. 한 명의 진행자가 플레이 화면과 응답을 관찰하고 아래 기록 양식을 작성한다.

## 기본 조작

| 목적 | 키보드 | 마우스 | 게임패드 |
|---|---|---|---|
| 대사 진행·선택 확정 | `Enter` 또는 `Space` | 왼쪽 클릭 | `A` |
| 기록 열기 | `L` | 화면 버튼 | `Y` |
| 자동 진행 | `A` | 화면 버튼 | `X` |
| 읽은 문장 스킵 | `S` | 화면 버튼 | 오른쪽 스틱 클릭 |
| 시네마틱 일시정지 | `P` | 화면 버튼 | `LB` |
| 시네마틱 요약 전환 | `R` | 화면 버튼 | `Y` |
| 시네마틱 결과로 이동 | `K` | 화면 버튼 | `B` |
| 닫기·뒤로 | `Esc` | 닫기 버튼 | `B` |

입력 상호작용은 실패 판정이 없다. 설정에서 `길게 누르기 대신 한 번 눌러 전환`과 `이미 본 상호작용 자동 완료`를 켤 수 있다.

## 세 분기 진입법

첫 공통 플레이에서 S06의 세 선택이 나타나면 화면의 `저장` 버튼으로 수동 저장한다. 이 수동 슬롯은 S06 선택 직전의 분기 진입점이다.

1. `추적`을 선택해 종장까지 플레이하고 결과를 기록한다.
2. 표지 또는 플레이 중 `불러오기`에서 수동 저장을 불러온 뒤 `수호`를 선택하고 결과를 기록한다.
3. 같은 수동 저장을 다시 불러온 뒤 `봉쇄`를 선택하고 결과를 기록한다.

각 분기에서 S08 이후 자동 저장이 갱신되어도 수동 저장 슬롯은 그대로 남아야 한다. 수동 저장이 사라지거나 다른 장면으로 바뀌면 결함으로 기록한다.

## 관찰 질문

각 질문은 먼저 1~5점으로 답하고, 이어서 짧은 이유를 적는다.

1. 이연이 직접 싸움을 조작하는 캐릭터가 아니라 선택과 의도를 통해 검대를 지휘한다는 점이 분명했는가?
2. S00의 두 선택이 서로 다른 우선순위를 뜻한다는 점을 선택 전에 이해했는가?
3. S02의 세 질문 중 고른 질문이 이후 정보에 남았다고 느꼈는가?
4. S06의 `추적·수호·봉쇄`가 예상한 사람·단서·노출 결과로 이어졌는가?
5. 9검과 108검이 단순 이펙트가 아니라 역할이 분리된 편대로 읽혔는가?
6. 결과 화면이 등급·경험치·명성 점수 없이도 선택의 대가를 이해시키는가?
7. 대사 속도, 자동 진행, 읽은 문장 스킵의 차이를 이해하기 쉬웠는가?
8. 길게 누르기/토글 대체 입력 중 선호 방식을 문제없이 사용할 수 있었는가?
9. 전체·요약·결과 시네마틱 중 어느 방식을 다시 보기에서 선택하겠는가?
10. 다음 장에서 가장 확인하고 싶은 사람, 단서 또는 갈등은 무엇인가?

추가 자유 질문:

- 가장 인상적인 한 장면은 무엇이었는가?
- 가장 이해하기 어려웠던 선택 또는 결과는 무엇이었는가?
- 진행이 멈췄거나 다음 행동을 몰랐던 순간이 있었는가?

## E4 판정 규칙

- 세 분기 모두 같은 SHA-256 빌드로 완료해야 한다.
- 진행 차단 또는 저장 손상은 `BLOCKER`다.
- 읽지 않은 문장이 스킵되면 `HIGH`다.
- 9/108 수량이 절차적 오버레이에서 다르거나 중복 슬롯이 보이면 `HIGH`다.
- 사람 응답과 결함 기록이 모두 모이기 전에는 `PASS` 또는 `KEEP`을 선언하지 않는다.
