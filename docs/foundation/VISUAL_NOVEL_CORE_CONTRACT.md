# VISUAL NOVEL CORE CONTRACT

> 상태: `CANONICAL`  
> 결정일: 2026-08-06  
> 적용 범위: 게임 기획, 스토리, UI, 상호작용, 검진 연출, Godot 구현, 프로젝트 전용 Skill

## 1. 최종 장르 정의

**《일인합격진: 검관을 끄는 남자》는 하드보일드 무협 다회차 비주얼 노블이다.**

108검과 검진은 전투 게임을 만들기 위한 시스템이 아니라, 이연의 판단과 감정을 가장 강하게 보여 주는 **서사적·시네마틱 언어**다.

```text
비주얼 노블 서사와 선택      75~80%
비실패형 감정 인터랙션       10~15%
108검 시네마틱과 결과 연출   10~15%
수동 전투·전술 게임          0%
```

## 2. 플레이어 역할

플레이어는 이연의 검을 조종하지 않는다.

플레이어가 맡는 것은 다음 세 가지다.

1. **시선** — 이연이 무엇을 먼저 보고 어떤 의미를 읽는가
2. **결단** — 계약·복수·수호·군림 중 어떤 원칙을 선택하는가
3. **무게** — 결정을 내리기 전 잠시 멈추고, 결정 뒤 남은 결과를 확인하는가

플레이어는 이연보다 전술적으로 뛰어나야 할 필요가 없다. 이연은 이미 완성된 강자이며, 플레이어 입력은 그의 능력을 대신 수행하는 것이 아니라 그의 판단에 **동참하는 감각**을 만든다.

## 3. 기본 플레이 루프

```text
대화와 장면 감상
→ 시선 선택 또는 짧은 관찰
→ 의미 있는 서사 선택
→ 결의를 체감하는 짧은 비실패 인터랙션
→ 선택에 대응하는 검진 시네마틱
→ 사람·정보·피해·관계의 후일담
→ 다음 장면 또는 다음 회차 해금
```

## 4. 허용되는 인터랙션

모든 인터랙션은 3~20초 안에 끝나며 실패·점수·정확도 판정이 없다.

### 4.1 시선 고정 `FOCUS_POINT`

장면 속 2~4개의 지점을 클릭하거나 포커스로 선택한다.

- 이연이 먼저 알아챈 정보가 달라진다.
- 짧은 내부 판단과 후속 대사가 달라진다.
- 정답·오답은 없다.
- 필수 정보는 숨기지 않는다.

### 4.2 결의 유지 `HOLD_INTENT`

마우스 버튼 또는 지정 키를 누르고 있는 동안 쇠사슬이 팽팽해지고 주변 음향이 가라앉는다.

- 정해진 시간이 지나면 자동 완료된다.
- 일찍 놓아도 실패하지 않고 다시 이어서 할 수 있다.
- 접근성 설정에서 `누르기 유지`를 `한 번 눌러 전환`으로 바꿀 수 있다.

### 4.3 쇠사슬 당기기 `CHAIN_PULL`

짧고 넓은 허용 범위 안에서 한 방향으로 드래그하거나 대체 입력을 누른다.

- 검진 시네마틱을 시작하는 촉각적 신호다.
- 빠르기·정확도·타이밍에 따른 보너스가 없다.
- 실패 애니메이션이 없다.

### 4.4 검 회수 `BLADE_RECALL`

전투 후 버튼을 누르고 있으면 검이 3개 또는 9개 단위로 돌아온다.

- 이연이 죽은 동료들의 검을 함부로 버리지 않는다는 태도를 체감시킨다.
- 첫 회차에는 짧게 사용하고, 재플레이에서는 자동 완료 또는 스킵할 수 있다.

### 4.5 결과 확인 `AFTERMATH_INSPECT`

상처, 열린 창문, 부서진 등불, 남은 표식 같은 1~3개 결과를 선택해 짧은 문장을 확인한다.

- 윤리 점수나 성공 등급을 표시하지 않는다.
- 선택의 가격을 화면 안의 실제 변화로 확인한다.

### 4.6 되돌릴 수 없는 선택 `WEIGHTED_CONFIRM`

처형·전면 복수처럼 되돌릴 수 없는 선택에만 1~2초의 길게 누르기 확인을 사용한다.

- 단순한 대화 선택에는 남용하지 않는다.
- 붉은색은 이 순간에만 제한적으로 사용한다.

상세 계약은 `docs/design/INTERACTION_LANGUAGE.md`가 담당한다.

## 5. 금지되는 게임 요소

다음은 프로젝트 계약 위반이다.

- 실시간 또는 턴제 전투 조작
- 적 HP·방어력·대미지 계산을 플레이어에게 노출
- 검대 드래그 배치와 목표 슬롯
- 전술 그리드, 이동 범위, 사거리, 쿨다운
- 12검대 덱 구성, 조합 프리셋, 강화·성장
- 조준, 회피, 패링, 콤보, QTE
- 입력 속도와 정확도에 따른 성공·실패
- 제한 시간으로 플레이어를 재촉하는 전술 화면
- 검진을 실행하기 위한 자원 게이지
- 전투 승리 점수, 랭크, 별점
- 주인공이 플레이어 실수 때문에 무능해지는 구조

## 6. 108검의 역할

108검은 다음 네 기능을 가진다.

1. **주인공의 정체성** — 이연은 한 사람이 아니라 하나의 군진처럼 보인다.
2. **선택의 확대** — 작은 서사 선택이 협곡·도시 규모의 결과로 확대된다.
3. **감정의 표현** — 이연이 말하지 않는 분노·주저·책임을 검의 정렬과 회수로 보여 준다.
4. **회차 차별화** — 같은 사건도 계약·복수·수호·군림에 따라 전혀 다른 검진 이미지가 된다.

검진은 반드시 미리 설계된 시네마틱 변형으로 제작한다. 플레이어가 검의 위치를 직접 짜지 않는다.

## 7. 다회차 구조

- 첫 회차부터 108검을 완전히 보여 준다.
- 회차 진행으로 이연의 능력이 증가하지 않는다.
- 이전 회차의 정보가 새로운 질문, 침묵, 행동 선택을 연다.
- 각 루트는 다른 원칙, 다른 대표 검진, 다른 인물 관계, 다른 후일담을 가진다.
- 진상 루트는 앞선 엔딩을 가짜로 만들지 않는다.
- 읽은 문장 스킵, 이미 본 인터랙션 자동 완료, 시네마틱 요약을 지원한다.

## 8. 화면 계약

### 서사 화면

- 배경과 인물이 화면의 65~80%를 차지한다.
- 대화창은 하단 25~30%를 넘지 않는다.
- 상시 전술 HUD를 표시하지 않는다.

### 감정 인터랙션 화면

- 실제 장면 위에 최소한의 포커스·쇠사슬·선택 표시만 추가한다.
- 별도의 전략 보드나 지도 화면으로 전환하지 않는다.

### 검진 시네마틱

- UI는 거의 사라진다.
- 일시정지·요약·스킵만 필요할 때 표시한다.

### 결과 화면

- 한 장의 후일담 이미지와 최대 네 줄의 결과 문장으로 구성한다.
- 성공·실패 등급 대신 사람, 정보, 피해, 검 회수를 보여 준다.

## 9. 장면 검수 질문

모든 장면은 다음을 통과해야 한다.

1. 이 장면의 중심은 대화·선택·감정인가?
2. 인터랙션을 제거해도 이야기는 진행되지만, 넣었을 때 이연의 심정이 더 잘 느껴지는가?
3. 플레이어 숙련 부족으로 이연이 약해지지 않는가?
4. 검진은 선택의 결과를 확대하는가?
5. 장면이 일반 액션 게임이나 전술 게임 UI처럼 보이지 않는가?
6. 결과가 다음 대사·관계·회차에 기억되는가?

## 10. 문서 충돌 처리

이 문서와 충돌하는 기존의 다음 표현은 폐기한다.

- `검대 배치`
- `목표 슬롯 할당`
- `BattleResolver`
- `Formation Battle Runtime`
- `전투 라운드`
- `검대 조합 프리셋`
- `전술 성공률`

기존 문서의 전투·전술 표현은 **서사 선택 뒤 실행되는 시네마틱 연출**로 재해석한다.
