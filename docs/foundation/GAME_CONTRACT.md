# GAME CONTRACT

## 1. 게임 정의

**《일인합격진: 검관을 끄는 남자》**는 108자루의 검을 상단전 의념으로 지휘하는 해결사 이연의 힘을, 서사 선택과 전술 배치와 3D 검진 시네마틱으로 체험하는 하드보일드 무협 비주얼 노블이다.

## 2. 플레이어 역할 판타지

플레이어는 약한 주인공을 성장시키지 않는다.

플레이어는 이미 완성된 강자 이연의 판단을 맡는다.

- 적을 이길 수 있는가가 아니라 어떻게 이길 것인가
- 누구를 죽이고 누구를 살릴 것인가
- 108검을 한 목표에 몰아넣을지 여러 목표로 나눌지
- 계약과 복수와 수호 중 무엇을 우선할지
- 완전한 승리 뒤 어떤 세상을 감당할지

플레이어가 느껴야 할 핵심 감정은 다음 순서다.

```text
등장 전 긴장
→ 전개 순간의 압도감
→ 진형을 읽는 지적 쾌감
→ 명령이 집행되는 통제감
→ 결과를 감당하는 냉정함
```

## 3. 핵심 기둥

### PILLAR-01 — 한 사람이 군진이다

108검은 장식이나 탄환이 아니다. 12개의 검대가 서로 다른 임무를 수행하며 전장을 재구성한다. 이연의 핵심 능력은 검을 많이 날리는 힘이 아니라 108개의 전투 판단을 동시에 유지하는 지휘 능력이다.

### PILLAR-02 — 강함은 보존하고 목적을 어렵게 한다

이연은 보통 적에게 전투력으로 밀리지 않는다. 게임 난이도는 다음에서 발생한다.

- 동시 목표
- 민간인과 구조물
- 생포와 증거
- 계약 시간
- 서로 양립하지 않는 요청
- 힘을 공개했을 때의 정치적 결과

### PILLAR-03 — 하드보일드는 선택의 가격이다

모든 올바른 선택에는 비용이 있다.

- 계약을 지키면 사람을 버릴 수 있다.
- 사람을 구하면 계약을 어길 수 있다.
- 복수를 끝내면 전쟁이 시작될 수 있다.
- 전쟁을 막으면 진실을 묻어야 할 수 있다.
- 강호를 굴복시키면 이연 자신이 폭군이 될 수 있다.

### PILLAR-04 — 다회차는 다른 승리의 체험이다

각 루트는 같은 사건의 대사만 바꾸지 않는다. 이연이 108검을 사용하는 목적, 전장, 시네마틱, 남는 질서가 달라야 한다.

## 4. 핵심 동사

| 동사 | 플레이 의미 |
|---|---|
| 관측한다 | 상단전 시야로 목표·위험·지형을 읽는다 |
| 배치한다 | 12검대를 임무와 공간에 할당한다 |
| 명령한다 | 죽임·생포·수호·봉쇄·추적 중 집행 원칙을 정한다 |
| 목격한다 | 선택한 검진이 3D 시네마틱으로 실행되는 것을 본다 |
| 감당한다 | 피해·증거·평판·루트 변화를 받아들인다 |

## 5. 반복 루프

### 30초 루프

```text
위협 인지
→ 목표 확인
→ 검대 또는 선택지 지정
→ 즉각 피드백
```

### 5분 루프

```text
대치와 정보 획득
→ 상단전 시야 진입
→ 2~4개 목표에 검대 배치
→ 검진 집행
→ 결과와 다음 갈등
```

### 한 세션 루프

```text
의뢰 또는 갈등
→ 인물과 세력의 요구 충돌
→ 한 개 이상의 전술 전투
→ 원칙 선택
→ 챕터 결과와 기록 해금
```

### 캠페인 루프

```text
공통부
→ 원칙 루트
→ 엔딩
→ 읽은 장면 스킵과 신규 정보
→ 다른 원칙 루트
→ 진상 루트
```

## 6. 이연 능력 계약

### 확정 능력

- 하단전이 파괴되어 일반적인 내공 운용 불가
- 상단전 의념으로 108검 동시 제어
- 12검대 각각에 독립 명령 유지
- 검의 진동·충돌·위치로 주변 감지
- 검을 발판·다리·방벽·구조물로 이용
- 내공 흐름이 없어 기감·점혈·흡성 계열 대응에 특이한 우위
- 웬만한 고수와 군대를 정면 제압 가능

### 운영 제약

운영 제약은 약화가 아니다.

- 한 검대가 두 곳에 동시에 존재할 수 없음
- 정밀 생포와 광역 방어는 같은 검대를 요구할 수 있음
- 검을 구조물에 고정하면 공격에 사용할 수 없음
- 도시 여러 곳을 동시에 통제할수록 플레이어의 배치 판단이 중요해짐
- 108검 전부 회수는 이연의 개인 규칙이며 결과 장면에 영향을 줌

### 금지 약점

- 반복적인 정신력 게이지 고갈
- 전투마다 코피·실신을 긴장 장치로 사용
- 근접하면 자동으로 무력해지는 설정
- 적이 상단전을 간단히 봉인
- 보스가 검진 전체를 무효화

## 7. 전투 승패 계약

기본 전투에는 전통적 HP·MP·레벨이 없다.

평가 대상:

- 핵심 목표 달성
- 부가 목표 달성
- 민간 피해
- 생포·증거 확보
- 계약 시간
- 검 회수
- 힘의 공개 수준
- 세력과 원칙 결과

이연은 전투에서 이겨도 사건에서 실패할 수 있다. 배드엔딩은 약해서 진 것이 아니라 선택한 승리가 더 큰 파국을 만든 결과여야 한다.

## 8. 다회차 원칙

| 원칙 | 질문 | 대표 승리 |
|---|---|---|
| 계약 | 약속은 누구의 죽음까지 정당화하는가 | 백야성 전체를 하나의 봉쇄진으로 만듦 |
| 복수 | 죄의 경계를 어디까지 넓힐 것인가 | 108명의 책임자를 동시에 처형 |
| 수호 | 증거와 계약보다 지금 살아 있는 사람이 우선인가 | 검의 다리와 방벽으로 대피 |
| 군림 | 강한 한 사람이 전쟁을 금지하면 평화인가 | 각 세력 수장 위에 검을 멈춰 세움 |
| 진상 | 네 원칙의 장점을 동시에 실행할 수 있는가, 그 대가는 무엇인가 | 12개 전장을 동시에 운영하는 완전한 일인합격진 |

## 9. 하드보일드 톤 계약

- 감정을 설명하기보다 행동과 선택으로 보여 준다.
- 이연은 자기소개보다 주변 반응으로 명성을 드러낸다.
- 유머는 냉소, 거래, 상황의 모순에서 나온다.
- 악인은 악해서가 아니라 사람을 도구로 보는 논리로 위험하다.
- 선한 인물도 자기 정의의 비용을 누군가에게 떠넘길 수 있다.
- 폭력 뒤에는 파손, 부상, 유가족, 정치적 공백이 남는다.
- 중요한 대사는 짧고 되돌릴 수 없는 행동 직전에 배치한다.
- 로맨스는 가능하지만 루트 보상이나 주인공의 핵심 동기가 아니다.

## 10. 출시 범위 초안

- 공통 루트: 약 2시간
- 네 개 원칙 루트: 각 3~4시간의 신규 콘텐츠
- 진상 루트: 4~5시간
- 전체 신규 플레이: 약 22~28시간
- 주요 엔딩: 5개
- 단기·파국 엔딩: 4~6개
- 핵심 3D 전투 세트피스: 10~12개
- 12개 검대
- 핵심 지휘검 12자루
- 108검 검명 기록
- 주요 인물 6명 내외
- 주 무대: 백야성과 관천협

수치는 프로토타입과 수직 슬라이스 결과로 조정 가능하다.
