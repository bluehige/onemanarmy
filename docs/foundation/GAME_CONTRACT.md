# GAME CONTRACT

> 상태: `CANONICAL DRAFT`  
> 상위 계약: `VISUAL_NOVEL_CORE_CONTRACT.md`

## 1. 게임 정의

**《일인합격진: 검관을 끄는 남자》**는 108자루의 검을 상단전 의념으로 운용하는 해결사 이연의 판단과 대가를 다회차로 체험하는 하드보일드 무협 비주얼 노블이다.

플레이어는 검을 직접 조종하지 않는다. 대화와 선택, 짧은 비실패형 인터랙션으로 이연의 시선·결의·책임을 체감하고, 선택의 결과가 108검 시네마틱과 후일담으로 나타나는 것을 본다.

## 2. 플레이어 판타지

- 이미 완성된 강자의 내면에 들어간다.
- 상황을 이해하지 못해서가 아니라, 무엇을 우선할지 선택한다.
- 작은 결단이 협곡과 도시 전체를 바꾸는 장면을 목격한다.
- 검진이 끝난 뒤 남은 사람·정보·피해를 외면하지 않는다.
- 여러 회차를 통해 같은 힘이 서로 다른 정의를 만드는 것을 확인한다.

## 3. 핵심 기둥

### PILLAR-01 — 비주얼 노블 우선

대화, 인물 관계, 선택, 회차별 진실과 후일담이 플레이의 중심이다.

### PILLAR-02 — 한 사람의 군진

108검은 `12검대 × 9검`의 질서로 움직이며 첫 장면부터 이연의 압도적 정체성을 보여 준다.

### PILLAR-03 — 힘이 아니라 사용 원칙이 갈린다

이연은 어떤 루트에서도 전투 숙련 부족으로 약해지지 않는다. 계약·복수·수호·군림 중 무엇을 위해 힘을 쓰는지가 갈린다.

### PILLAR-04 — 손으로 느끼는 정적

시선 선택, 쇠사슬을 쥐는 누르기, 검 회수처럼 실패 없는 짧은 인터랙션이 이연의 심정을 보강한다.

### PILLAR-05 — 하드보일드한 대가

모든 중요한 선택 뒤에는 부상자, 놓친 정보, 무너진 관계, 정치적 책임 같은 회복 불가능한 흔적이 남는다.

## 4. 핵심 루프

```text
대화·장면
→ 관찰 또는 시선 선택
→ 서사 선택
→ 짧은 감정 인터랙션
→ 선택별 검진 시네마틱
→ 후일담·기록·분기
```

## 5. 의미 있는 선택

좋은 선택은 다음 조건을 가진다.

- 이연은 모든 선택을 유능하게 실행할 수 있다.
- 무엇을 확보하고 무엇을 포기하는지 사전에 이해할 수 있다.
- 결과가 대사 한두 줄이 아니라 인물·정보·공간·정치 상태를 바꾼다.
- 선악 정답이 아니라 원칙의 차이를 표현한다.
- 이후 장면과 회차가 결과를 기억한다.

예:

- 도주자를 잡아 배후 정보를 얻지만 객잔 사람의 부상을 막지 못한다.
- 사람을 지키지만 도주자를 놓친다.
- 객잔 전체를 봉쇄하지만 이연의 힘이 백야성 전체에 알려진다.

## 6. 인터랙션 계약

허용 타입:

- `FOCUS_POINT`
- `HOLD_INTENT`
- `CHAIN_PULL`
- `BLADE_RECALL`
- `AFTERMATH_INSPECT`
- `WEIGHTED_CONFIRM`

공통 조건:

- 실패 없음
- 점수 없음
- 타이밍 보너스 없음
- 20초 이내
- 대체 입력 제공
- 재플레이 자동 완료 또는 스킵
- 실제 선택은 텍스트와 맥락으로 명확히 제공

## 7. 108검 계약

- 첫 10분 안에 전면 전개한다.
- 플레이어가 검 108개를 개별 선택하지 않는다.
- 검대의 역할은 시네마틱 안에서 공간적으로 읽힌다.
- 이연의 작은 손동작과 거대한 결과를 연결한다.
- 시네마틱은 선택별로 미리 저작된 변형이다.
- 검진이 끝난 뒤 검 회수와 결과 확인에 시간을 준다.
- 적을 베는 장면만 반복하지 않고 차단·구조·운반·봉쇄·증언을 보여 준다.

## 8. 다회차 계약

주요 원칙:

- `CONTRACT`
- `VENGEANCE`
- `PROTECTION`
- `DOMINION`
- `TRUTH`

각 루트는 다음 네 요소가 모두 달라야 한다.

1. 중심 원칙
2. 주된 동맹과 갈등 관계
3. 대표 108검 시네마틱
4. 정치적·개인적 후일담

다회차 보상:

- 새로운 질문과 침묵
- 이전에는 읽지 못한 인물의 의도
- 새로운 장면 진입
- 다른 검진 결과
- 검주 기록과 사건 연표

능력치·장비·검대 성장은 없다.

## 9. 하드보일드 계약

하드보일드는 다음으로 표현한다.

- 썩거나 타협한 조직
- 이연의 개인 규칙
- 돈·계약·빚·배신
- 빠른 폭력과 길게 남는 결과
- 감정을 설명하지 않는 행동
- 옳은 선택에도 남는 비용

비, 어둠, 술, 피만으로 하드보일드라고 판단하지 않는다.

## 11. MVP 질문

MVP는 다음을 증명해야 한다.

> 플레이어가 대화와 선택 중심의 비주얼 노블 흐름을 유지하면서, 실패 없는 짧은 인터랙션을 통해 이연의 시선과 결의를 더 깊게 느끼고, 108검 시네마틱을 다음 선택을 보고 싶게 만드는 핵심 상품으로 인식하는가?

## 12. 폐기·재설계 기준

### 유지

- 이연과 108검이 구매 이유로 인식됨
- 인터랙션이 감정을 보강하고 이야기를 끊지 않음
- 다른 선택 결과를 보기 위한 재플레이 의향 확인

### 재설계

- 인터랙션이 미니게임처럼 느껴짐
- 시네마틱이 길어 서사 템포를 끊음
- 선택의 대가가 화면에서 읽히지 않음

### 폐기 또는 축소

- 인터랙션을 제거한 버전이 반복 테스트에서 더 몰입도가 높음

이 경우 인터랙션을 축소하되 비주얼 노블과 108검 시네마틱은 유지한다.
