# PROTOTYPE BRIEF — EXP-001 / EXP-002

> 상위 계약: `VISUAL_NOVEL_CORE_CONTRACT.md`

## 1. 실험 목적

이 프로젝트의 핵심 위험은 전투 시스템이 아니다.

검증할 것은 다음 두 가지다.

1. 108검 시네마틱이 이연을 `한 사람의 군진`으로 보이게 하는가
2. 실패 없는 짧은 인터랙션이 비주얼 노블의 흐름을 깨지 않고 이연의 심정을 더 잘 느끼게 하는가

---

# EXP-001 — 108검 시네마틱 가독성

## 단일 가설

플레이어는 이연의 작은 쇠사슬 동작 뒤 108검이 12검대의 질서로 움직이는 장면을 보고, 그를 염동력 사용자나 검을 난사하는 마법사가 아니라 혼자 전장을 통제하는 완성형 무인으로 이해한다.

## 프로토타입 범위

- 관천협 5~8분 장면
- 대화와 선택 1회
- `HOLD_INTENT` 또는 `CHAIN_PULL` 1회
- 9 → 36 → 72 → 108검 전개
- 선택별 시네마틱 2종
- `BLADE_RECALL` 1회

## 제외

- 전술 배치
- 목표 슬롯
- 전투 라운드
- HP·대미지
- 전체 StoryRuntime
- 저장·도감·전체 UI
- 최종 자산

## KEEP 기준

7명 테스트 기준:

- 5명 이상이 이연을 `한 사람의 군진`과 동등한 의미로 설명
- 5명 이상이 검들의 역할 차이를 설명
- 5명 이상이 첫 시네마틱을 핵심 매력으로 지목
- 이연이 약하거나 조작을 못 한다는 반복 지적 1명 이하

# EXP-002 — 비주얼 노블 감정 인터랙션

## 단일 가설

플레이어는 `시선 선택 → 서사 선택 → 쇠사슬을 쥐는 짧은 입력 → 시네마틱 → 결과 확인` 흐름을 전투 미니게임이 아니라 이연의 판단에 동참하는 비주얼 노블 표현으로 받아들인다.

## 프로토타입 범위

CH01에서 다음 구간만 연결한다.

```text
객잔의 긴장
→ FOCUS_POINT: 창문 / 등불 / 행상인의 손
→ 추적 / 수호 / 봉쇄 선택
→ HOLD_INTENT
→ 선택별 9검 시네마틱
→ AFTERMATH_INSPECT
→ BLADE_RECALL
```

## 계측

- 장면 완료 시간
- 인터랙션 재시도 횟수
- 안내를 읽지 못한 입력
- 선택 분포
- 시네마틱 스킵 여부
- 재플레이에서 자동 완료 사용 여부
- E4 인터뷰 응답

## KEEP 기준

- 7명 중 5명 이상이 인터랙션이 이연의 결의나 감정 이해에 도움 됐다고 응답
- 7명 중 5명 이상이 비주얼 노블 흐름이 유지됐다고 응답
- 7명 중 2명 이하만 미니게임처럼 느꼈다고 응답
- 입력 때문에 장면 진행에 실패한 사용자 0명
- 7명 중 4명 이상이 다른 결과 재생 의향

## REDESIGN 기준

- 누르기·드래그가 불필요한 노동으로 느껴짐
- 인터랙션 안내가 장면보다 먼저 보임
- 시네마틱 시작이 늦어 템포가 끊김
- 플레이어가 입력 성공 여부를 걱정함

## KILL / 축소 기준

인터랙션이 없는 A안이 반복 테스트에서 더 높은 몰입도를 보이면, 해당 인터랙션을 제거하거나 단일 클릭으로 축소한다.

108검 시네마틱과 서사 선택은 유지한다.

---

## 공통 기술 원칙

- 프로토타입 결과는 결정론적이다.
- 입력은 시네마틱 시작과 감정적 템포만 담당한다.
- 모든 인터랙션에 대체 입력이 있다.
- 실패 상태와 점수가 없다.
- 프로토타입 코드를 검토 없이 제품 코드로 승격하지 않는다.
