# FORMATION CINEMATIC LANGUAGE

> 파일 경로는 기존 참조 호환을 위해 유지한다.  
> 이 문서의 `전투`는 플레이어 조작 전투가 아니라 **서사 선택 뒤 재생되는 저작 시네마틱**을 뜻한다.

## 1. 설계 목표

108검은 수량 효과가 아니라 질서, 역할, 통제와 결과로 매력적이어야 한다.

> 진형이 완성된 순간 적은 이미 진 것이다.

이연의 몸은 적게 움직이고 검진은 크게 움직인다. 카메라는 손가락, 쇠사슬, 검 코등이 같은 작은 동작을 먼저 보여 준 뒤 협곡·도시 규모의 결과로 확장한다.

플레이어는 검대를 배치하거나 검을 조종하지 않는다. 서사 선택 ID가 시네마틱 변형을 결정한다.

## 2. 백팔검관

- 낮고 긴 흑철·목재 관형 수레
- 12개 검갑
- 검갑 하나당 9검
- 손목과 검관을 잇는 쇠사슬
- 12개 잠금의 순차 해제
- 마법 수납 공간이나 미래 병기함 금지

## 3. 시네마틱 기본 문법

모든 주요 검진은 다음 순서를 사용한다.

```text
장면의 위험을 먼저 보여 줌
→ 이연이 무엇을 보는지 고정
→ 서사 선택
→ 결의 인터랙션
→ 작은 명령 동작
→ 검대가 역할별로 정렬
→ 진형이 잠기는 정지
→ 짧고 정확한 집행
→ 사람·정보·공간의 결과
→ 검 회수 또는 남은 검의 의미
```

### 필수 숏

1. 이연의 미세 동작
2. 공간 관계가 읽히는 원경
3. 역할이 다른 검대 최소 2개
4. 적 또는 보호 대상이 결과를 이해하는 반응
5. 집행 뒤 남은 물리적 흔적

미장센 숏만으로 공간 논리를 대체하지 않는다.

## 4. 선택과 시네마틱 연결

```yaml
formation_cinematic:
  id: CIN-CH01-TRACK
  source_choice: CH01-CHOICE-TRACK
  sword_count: 9
  lee_yeon_gesture: chain_hold
  visual_roles:
    - route_cut
    - sleeve_pin
    - hostage_delay
  shot_sequence: []
  aftermath:
    - fugitive_captured
    - innkeeper_injured
  replay_summary_id: ""
```

- 동일한 선택은 동일한 결과를 낸다.
- 선택의 결과를 시네마틱 내부에서 다시 계산하지 않는다.
- 분기 상태는 StoryRuntime이 결정하고 CinematicDirector가 표현한다.
- 검의 충돌·절단은 저작된 애니메이션이며 물리 시뮬레이션이 게임 규칙을 정하지 않는다.

## 5. 검 수에 따른 연출 기능

| 검 수 | 서사 기능 | 예시 |
|---:|---|---|
| 1 | 개인적 경고·결단 | 무명검 직접 사용 |
| 9 | 실내 정밀함 | 객잔의 구검 |
| 18 | 두 대상을 동시에 보호·추적 | 좁은 거리·호위 |
| 36 | 지형과 이동로 변화 | 검교·화살 차단 |
| 54 | 세 사건의 병렬 결과 | 불타는 시장 |
| 72 | 도시·군대 규모 통제 | 성벽·대피로 |
| 108 | 한 루트의 원칙을 상징하는 대형 장면 | 관천협·최종 검진 |

검 수가 많을수록 더 강한 공격이라는 단순 계단을 만들지 않는다.

## 6. 12검대의 사용

12검대 설정은 세계관과 시각 설계 단위다.

- 플레이어 메뉴에서 카드·덱·레벨로 관리하지 않는다.
- 장면마다 필요한 검대만 시네마틱 안에서 드러낸다.
- 이름을 몰라도 기능이 실루엣과 움직임으로 읽혀야 한다.
- 검대 설명은 검흔록에서 선택적으로 제공한다.

대표 역할:

- 무음: 실내 정밀 제압
- 반월: 화살·암기 차단
- 천라: 이동로 제한
- 철성: 구조물 지지
- 용회: 운반·통로
- 파진: 합격진 분해
- 추혼: 추적
- 봉맥: 생포
- 낙성: 상공 제압
- 귀류: 힘과 투사체 방향 전환
- 쇄로: 문·골목 봉쇄
- 무명: 이연 주변 예비·복합 임무

## 7. 이연의 명령 동작

허용:

- 쇠사슬 한 고리를 당김
- 엄지로 검 코등이를 튕김
- 두 손가락을 접음
- 검집 끝을 발뒤꿈치로 침
- 손목에 쇠사슬을 한 번 더 감음
- 시선을 한 대상에서 다른 대상으로 옮김

금지:

- 팔을 크게 휘두르는 주문 동작
- 진법 이름을 계속 외침
- 고통과 과부하로 몸을 비틈
- 검을 통제하지 못해 당황

## 8. 감정 표현

검진은 이연의 감정을 말 대신 표현한다.

| 감정 | 검진 표현 |
|---|---|
| 경계 | 검이 공격하지 않고 사각에서 정지 |
| 결의 | 검대 간격이 동시에 잠김 |
| 분노 | 쇠사슬 장력이 높아지고 검의 움직임이 더 짧고 직접적 |
| 주저 | 검은 이미 배치됐지만 마지막 명령만 멈춤 |
| 책임 | 전투 뒤 검을 천천히 회수하고 피해를 확인 |
| 애도 | 한 자루의 귀환 또는 검주 기록에 시간을 줌 |

## 9. CH01 시네마틱

### 관천협

선택 A `지휘관을 묶는다`:

- 36검 화살 차단
- 36검 기병 진로 변경
- 27검 병기 연결부 절단
- 9검 지휘관 생포
- 피난민 통로가 한 박자 늦게 열림

선택 B `길을 먼저 연다`:

- 검대가 양쪽에 통로를 먼저 형성
- 피난민 이동
- 기병대는 벽과 봉쇄선에 묶임
- 지휘관은 놓치지만 이연의 비개입 원칙 강조

### 객잔의 구검

공통 자동 제압:

- 암기 요격
- 칼집 고정
- 계단 봉쇄
- 민간인 보호선
- 사수 시야 차단

선택 변형:

- 추적: 3검이 외부 퇴로를 자르고 내부 대응이 늦음
- 수호: 인질과 불길에 검을 집중하고 도주자를 놓침
- 봉쇄: 9검이 출구를 하나의 폐쇄 진으로 연결하고 힘이 공개됨

플레이어는 이 위치를 직접 지정하지 않는다.

## 10. 전체 전개 게이트

108검 전체 전개는 다음을 답해야 한다.

- 왜 지금 108검이 필요한가
- 이 선택이 어떤 원칙을 표현하는가
- 이전 전체 전개와 무엇이 다른가
- 검이 멈춘 뒤 어떤 이미지가 남는가
- 사람·정보·도시가 어떻게 달라졌는가

## 11. 반복 방지

- 모든 장면을 검날 날개 구도로 만들지 않는다.
- 모든 검이 한 목표로 돌진하지 않는다.
- 속도선·불꽃·카메라 흔들림으로 역할 부족을 숨기지 않는다.
- 처형 장면만 반복하지 않는다.
- 첫 회차와 다른 회차의 시네마틱은 목표와 후일담이 달라야 한다.

## 12. 기술 후보

- 12 `MultiMeshInstance3D` 또는 동등한 검대 단위 렌더링
- 9 인스턴스씩 총 108검
- 데이터 기반 `FormationCinematic`
- AnimationPlayer 또는 커스텀 시퀀서
- 카메라·VFX·오디오 큐
- 근접 숏의 대표검만 별도 고품질 메시
- 풀링된 트레일과 파편

이 구조는 시각 표현 전용이다. BattleResolver, 전술 AI, 검대 충돌 판정은 만들지 않는다.

## 13. 검증

관객이 설명 없이 다음을 말할 수 있어야 한다.

- 이연이 무엇을 선택했는가
- 어느 검들이 어떤 역할을 했는가
- 왜 적이 빠져나가지 못했는가
- 누가 살고 무엇을 놓쳤는가
- 이연이 통제하고 있었다는 근거가 무엇인가

시네마틱의 최종 승인은 실제 게임 화면에서 대화 전후 맥락과 함께 판단한다.
