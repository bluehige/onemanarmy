# FORMATION COMBAT & CINEMATICS

## 1. 설계 목표

108검은 화면을 채우는 수량 효과가 아니라 **질서, 역할, 통제**로 매력적이어야 한다.

플레이어가 모든 전투에서 느껴야 하는 문장은 다음과 같다.

> 진형이 완성된 순간 적은 이미 진 것이다.

이연의 몸은 적게 움직이고 검진은 크게 움직인다. 카메라는 손가락, 쇠사슬, 검 코등이 같은 작은 물리 동작을 먼저 보여 준 뒤 도시·협곡 규모의 결과로 확장한다.

## 2. 백팔검관

### 외형

- 낮고 긴 흑철 관 형태의 수레
- 12개 검갑이 내부에 방사형으로 접힘
- 검갑 하나당 9검
- 손목과 검관을 연결하는 짧은 쇠사슬
- 바퀴와 하부에는 수리 흔적과 오래된 혈흔
- 검관 표면에 천류문 문양을 크게 새기지 않고 잠금 구조에만 잔존

### 전개

1. 쇠사슬 당김
2. 12개 잠금장치 순차 해제
3. 검관 외피가 12개 패널로 열림
4. 검갑이 이연 뒤의 원호 위치로 이동
5. 지휘검이 먼저 떠오름
6. 종속검 8자루가 지휘검을 기준으로 정렬
7. 12검대가 하나의 대진을 형성

검은 전개 직후 흔들리지 않는다. 정확한 간격과 각도로 정지하는 것이 위압감의 핵심이다.

### 시각 구분

색상만으로 구분하지 않는다.

- 검신 형태
- 코등이 문양
- 편대 실루엣
- UI 문장
- 지휘검 아이콘
- 전개 음향

12검대를 한꺼번에 처음 가르치지 않는다. 설정상 이연은 모두 운용하지만, 플레이 UI는 장면에 필요한 3~4개부터 노출한다.

## 4. 검 수와 장면 규모

| 검 수 | 주 용도 | 장면 규칙 |
|---:|---|---|
| 1 | 경고, 처형, 개인 결단 | 이연이 직접 잡는 순간은 특별해야 함 |
| 9 | 객잔·방·골목 정밀전 | 빠르고 조용하며 피해 최소화 |
| 18 | 호위·추격·암기 차단 | 두 임무를 동시에 보여 줌 |
| 36 | 고수전·다리·협곡 | 입체 경로와 적 유도 |
| 54 | 구조와 전투 동시 | 화면 분할 또는 교차 편집 |
| 72 | 성문·군대·대피 | 지형을 바꾸는 규모 |
| 108 | 루트 최종 결전 | 작품의 의미와 선택을 표현 |

108검 전체 전개는 숫자 상승 연출이 아니라 목적 변화여야 한다.

## 5. 전투 플레이 구조

### Phase 1 — 대치

- 적과 상황 제시
- 이연이 즉시 죽일 수 있음을 보여 주는 작은 행동
- 동시에 지켜야 할 목표 공개
- 플레이어 질문 한 문장 표시

### Phase 2 — 상단전 시야

시간이 정지하는 것이 아니라 이연의 인지가 압축된 연출이다.

표시 요소:

- 목표 노드
- 위험 경로
- 검대 토큰
- 예상 결과선
- 충돌 표시
- 핵심/부가 목표
- 정보 불확실성

### Phase 3 — 배치

- 검대 선택
- 목표 선택
- 명령 동사 선택
- 예상 직접 결과 확인
- 확정

한 라운드의 핵심 입력은 3~6회 이내로 제한한다.

### Phase 4 — 집행

- 검대 전개
- 적 대응
- 선택 결과
- 부가 목표의 성공·실패
- 다음 라운드가 있으면 새로운 위협

### Phase 5 — 귀환과 결과

- 검 회수
- 검관 잠금
- 인물·도시·증거 결과
- 이연의 짧은 행동
- 다음 장면

## 6. 결과 모델

전투 해석은 결정론적이다. 숨은 확률로 중요한 인물이 죽지 않는다.

```text
BattleOutcome =
  core_objectives
+ optional_objectives
+ casualties
+ evidence
+ contract_state
+ sword_recovery
+ public_exposure
+ route_flags
```

검대의 역할과 목표 조건이 맞으면 성공한다. 정보 부족이나 충돌은 배치 전에 알려 주되, 상세 결과는 집행에서 드러낸다.

### 백팔검 절명진

- 108검
- 대상 108명에 한 자루씩 할당
- 칼날은 사각에서 정지
- 이연이 명령하기 전 아무도 죽지 않음
- 손가락 하나를 접으면 검로가 동시에 닫힘

### 일인합격진

- 108검

- 살상, 수호, 봉쇄, 운반, 파진을 동시에 수행

- 최종적으로 자신의 한 자루를 직접 듦

## 8. 적 대응 설계

적이 검진을 무효화하지 않고 **목표 충돌을 만든다**.

| 적 유형 | 대응 방식 | 플레이 질문 |
|---|---|---|
| 기병대 | 넓은 이동과 속도 | 죽이지 않고 진로를 바꿀 수 있는가 |
| 궁수대 | 다수 투사체 | 방어에 검대를 얼마나 고정할 것인가 |
| 합격진 | 지휘점과 연결선 | 어느 결절을 먼저 파괴할 것인가 |
| 암살자 | 민간인과 섞임 | 광역 공격 없이 구분할 수 있는가 |
| 내공 고수 | 한 점 돌파 | 여러 사각을 동시에 만들 수 있는가 |
| 인질범 | 목표 결합 | 생포와 수호를 어떻게 나눌 것인가 |
| 방화·붕괴 | 비인간 위협 | 검을 구조물로 쓸 것인가 추격에 쓸 것인가 |
| 백팔인진 | 12개 인간 부대 | 12검대의 역할을 어떻게 맞출 것인가 |

## 9. 시네마틱 문법

### 기본 샷 순서

```text
작은 원인
→ 공간 관계
→ 검대 전개
→ 적의 이해
→ 진형 완성
→ 짧은 집행
→ 결과 정지화면
→ 귀환
```

### 필수 대비

- 손가락 2cm 움직임 ↔ 성문 전체 봉쇄
- 쇠사슬 한 번 당김 ↔ 108검 전개
- 이연의 정지 ↔ 검진의 고속 이동
- 108검의 장대함 ↔ 마지막 한 자루의 짧은 처형
- 전투의 소음 ↔ 명령 직전 정적

### 금지 카메라

- 검을 따라 무작정 흔들리는 카메라
- 모든 검을 한 화면에 계속 넣는 원경
- 검의 수만 보여 주고 목표 관계를 잃는 회전
- 과도한 슬로모션 반복
- 이연이 허공에서 춤추듯 손을 휘두르는 구도
- 매 전투 같은 360도 회전 샷

### 대표 샷 라이브러리

1. `LOCK_SEQUENCE_CLOSE`: 잠금장치 12개 순차
2. `EYE_TO_FIELD`: 이연 눈 클로즈업에서 전장 초광각
3. `CHAIN_COMMAND`: 쇠사슬 당김과 검대 반응
4. `FORMATION_TOP`: 진형 관계를 읽는 탑뷰
5. `ENEMY_REALIZATION`: 적이 이미 포위됐음을 깨닫는 중경
6. `SWORD_STEP`: 검 발판 이동
7. `CITY_REVEAL`: 카메라가 멀어지며 도시 전체가 진 내부임을 공개
8. `LAST_SWORD_HAND`: 이연이 직접 검을 잡는 손
9. `RETURN_COUNT`: 검이 9개 단위로 귀환
10. `EMPTY_SPACE_RESULT`: 검이 지나간 뒤 남은 공간과 결과

## 10. 애니메이션 구조

### 데이터 단위

```yaml
formation_sequence_id: seq_canyon_108_blockade
duration_sec: 24.0
squads:
  - squad_id: SQ-02
    path_track: arrows_intercept
    start_beat: 2
    end_beat: 5
beats:
  - id: 1
    camera: LOCK_SEQUENCE_CLOSE
    command_event: open_case
  - id: 2
    camera: FORMATION_TOP
    command_event: assign_intercept
outcome_bindings:
  - objective_id: protect_refugees
    success_variant: protect_success
    fail_variant: protect_fail
```

### 표현 계층

- `Tactical Representation`: UI 토큰과 예상 경로
- `Cinematic Representation`: 12개 SwordSquadRenderer3D
- `Hero Sword Representation`: 근접 샷용 개별 MeshInstance3D
- `Impact Representation`: 충돌 순간 임시 VFX와 사운드
- `Aftermath Representation`: 파손·부상·고정된 검

## 11. 3D 렌더링 후보

- 12개 `MultiMeshInstance3D`, 각 9인스턴스
- 검대별 공유 메시와 재질
- 인스턴스 Transform과 Custom Data로 위치·상태·강조 전달
- 카메라 근접 검은 별도 `MeshInstance3D`로 승격
- 궤적은 검 108개 각각의 긴 파티클 대신 검대 단위 또는 중요 검 단위
- VFX 풀링
- 전투 중 실제 물리 충돌 대신 결정론적 접점과 타이밍 사용
- 디버그 모드에서 검대 ID, 경로, 목표, beat 표시

최종 구조는 EXP-001 비교 결과로 승인한다.

## 12. 성능·가독성 예산 초안

- 목표: 1920×1080, 60fps
- 108검 렌더러: 검대당 1 draw submission 목표
- 동시 고비용 트레일: 12개 이하
- 동시 대형 파티클 시스템: 6개 이하
- 카메라 모션 블러 기본 미사용
- 화면 흔들림 기본 약함, 옵션 제공
- 핵심 목표를 가리는 스파크·연기 금지
- 검대 간 최소 화면 간격을 샷별로 검증
- 핵심 전개 구간 프레임타임 캡처 필수

수치는 임시 예산이며 실제 기기 측정으로 갱신한다.

## 13. 완료 판정

검진 하나가 완료됐다고 말하려면 다음 증거가 필요하다.

1. Formation 데이터가 유효함
2. 모든 검이 시작·종료 위치를 가짐
3. 선택한 목표와 시네마틱 결과가 일치
4. 카메라에서 검대 역할이 구분됨
5. 귀환 후 108검 수가 일치
6. 1080p 성능 캡처
7. 지원 입력으로 처음부터 끝까지 실행
8. 실제 플레이어가 선택과 결과의 인과를 설명

자동 테스트만으로 `멋있다`를 승인하지 않는다.
