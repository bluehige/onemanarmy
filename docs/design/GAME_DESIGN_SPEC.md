# GAME DESIGN SPEC

## 1. 제품 개요

| 항목 | 정의 |
|---|---|
| 작업명 | 일인합격진: 검관을 끄는 남자 |
| 장르 | 시네마틱 전술 비주얼 노블 / 하드보일드 무협 |
| 엔진 | Godot 4.6.3 |
| 플랫폼 | Windows PC |
| 시점 | 서사 장면 2D/2.5D, 전투 장면 3D |
| 입력 | 마우스·키보드, 출시 시 게임패드 대응 |
| 대상 | 무협, 강한 주인공, 선택형 서사, 전술 연출을 선호하는 성인 플레이어 |
| 핵심 상품 | 108검을 12개 검대로 지휘해 전장을 설계하고, 그 결과를 시네마틱으로 목격하는 경험 |

## 2. 캠페인 구조

```text
프롤로그
→ 공통 루트 5장
→ 원칙 루트 1개
→ 엔딩
→ 읽은 문장 스킵 / 검흔록 갱신
→ 다른 원칙 루트
→ 3개 이상 주요 엔딩 완료
→ 진상 루트
```

### 목표 플레이 시간

- 프롤로그 + 공통부: 2시간 내외
- 원칙 루트: 각 3~4시간 신규 콘텐츠
- 진상 루트: 4~5시간
- 첫 엔딩: 6~8시간
- 전체: 22~28시간

시간은 수직 슬라이스의 실제 읽기·입력·시네마틱 속도로 다시 산정한다.

## 3. 핵심 플레이 루프

### 서사 단계

- 의뢰와 갈등을 받는다.
- 인물의 요구, 숨은 비용, 시간 제한을 파악한다.
- 대화 선택으로 원칙과 전투 목표를 정한다.
- 조사 장면은 전투 배치에 필요한 목표·지형·제약을 제공한다.

### 관측 단계

`상단전 시야`로 전환한다.

플레이어가 확인하는 정보:

- 핵심 목표
- 보호 대상
- 적 지휘점
- 위험 경로
- 사용 가능한 검대
- 검대 배치 시 예상되는 직접 결과
- 동시에 달성할 수 없는 충돌

### 배치 단계

12개 검대 중 필요한 검대를 목표 슬롯에 할당한다.

전투마다 모든 검대를 조작하지 않는다. 기본은 3~6개 검대이며, 최종전에서만 12개를 모두 운용한다.

### 집행 단계

선택한 배치를 바탕으로 데이터 기반 3D 시네마틱을 실행한다.

- 플레이어는 결과를 즉시 알아볼 수 있어야 한다.
- 카메라는 선택한 검대를 먼저 보여 준다.
- 실패한 부가 목표는 왜 실패했는지 장면으로 드러난다.
- 주요 전투는 짧은 추가 선택 또는 수정 명령을 1~3회 제공한다.

### 결과 단계

다음 상태를 갱신한다.

- `contract_integrity`: 계약 이행
- `vengeance_pressure`: 복수 선택
- `protection_cost`: 구한 사람과 포기한 정보
- `dominion_exposure`: 힘을 공개하고 질서를 강제한 정도
- 인물 생존·부상·신뢰
- 증거와 기록
- 민간 피해
- 검 회수
- 루트·장면 플래그

숫자는 내부 데이터로 유지하되, 플레이어에게 모든 수치를 노출하지 않는다. 결과 화면은 원인과 결과를 문장·아이콘·장면으로 설명한다.

## 4. 전투 디자인

### 전투의 질문

> 지금 가진 108검으로 적을 이기는 방법이 아니라, 서로 충돌하는 목표 중 무엇을 어떤 방식으로 완수할 것인가?

### 전투 단위

- `Battle Scenario`: 장소, 위협, 목표, 시간, 등장 인물
- `Objective`: 핵심·부가·숨은 목표
- `Sword Squad`: 9검 단위 역할
- `Formation Command`: 검대와 목표를 연결하는 명령
- `Resolution Beat`: 선택 결과를 실행하는 시네마틱 단위
- `Consequence`: 서사·루트·인물 상태 변화

### 기본 명령

- `제거`: 목표를 확실히 죽임
- `생포`: 움직임과 병기를 봉쇄
- `수호`: 사람·증거·구조물을 방어
- `봉쇄`: 길·문·공간을 닫음
- `유도`: 적의 이동을 원하는 경로로 바꿈
- `추적`: 도주자를 놓치지 않음
- `파진`: 적의 합격진·방어 구조를 분해
- `운반`: 검을 발판·다리·들것으로 사용

### 난이도

난이도는 적 HP 증가가 아니라 다음으로 조절한다.

- 동시에 제시되는 목표 수
- 검대 역할의 중첩
- 시간 압박
- 불완전 정보
- 민간인·구조물 제약
- 적 진법의 대응 패턴
- 한 선택이 다음 라운드에 만드는 결과

### 실패

- 이연 사망을 일반 실패로 사용하지 않는다.
- 핵심 목표 실패 시 즉시 다른 장면 또는 단기 엔딩으로 진행할 수 있다.
- 부가 목표 실패는 이후 인물·정보·전투 조건을 바꾼다.
- 플레이어가 원하면 챕터 시작 또는 직전 전술 선택으로 돌아갈 수 있다.

## 5. 진행과 보상

### 능력치 성장 없음

이연은 이미 12검대와 주요 검진을 알고 있다.

게임 진행 보상은 다음이다.

- 새로운 상황에서 기존 검진의 용도를 발견
- 검대 조합 프리셋 해금
- 과거 검주의 기록
- 장면·인물·세력 정보
- 읽은 문장 스킵과 신규 장면 표시
- 루트 맵
- 전투 재생과 다른 배치 비교
- 진상 루트 선택지

UI가 기능을 순차 공개하더라도 세계관상 이연이 새로 배운 것으로 표현하지 않는다. 플레이어에게 필요한 시점에 지휘 인터페이스가 열리는 것이다.

### 검흔록

다회차 기록 화면이다.

구성:

- 주요 선택과 결과
- 본 엔딩
- 발견한 검주
- 해금된 검대 조합
- 루트별 미확인 분기
- 전투 재생
- 인물 생존 상태 비교

스포일러가 되는 미확인 정보는 이름을 숨기고 빈 위치만 표시한다.

## 6. 서사 선택 규칙

### 의미 있는 선택

좋은 선택은 즉시 이익과 장기 비용이 다르다.

예:

- 북문을 닫으면 계약은 지키지만 피난민이 고립됨
- 북문을 열면 사람을 구하지만 적 지원군도 들어옴
- 지휘관을 죽이면 전투가 쉬워지지만 배후 증거를 잃음
- 생포하면 정보는 얻지만 다른 목표에 검대를 덜 배치함
- 힘을 공개하면 전쟁을 즉시 막지만 각 문파가 이연을 공동의 적으로 규정함

### 금지 선택

- 정보 없이 운으로 고르는 선택
- 결과가 대사 한두 줄만 다른 선택
- 명백한 선행/악행 버튼
- 호감도 정답
- 이연이 무능하거나 상황을 이해하지 못해서 생기는 선택
- 전투가 끝난 뒤 의미 없이 결과를 고르는 선택

## 8. 대표 세트피스

1. **관천협의 108검**  
   첫 10분 안에 전면 전개. 군대를 죽이지 않고 협곡을 지배한다.

2. **객잔의 구검**  
   이연이 술잔을 내려놓지 않은 채 9검으로 20명을 제압한다.

3. **빗속의 검교**  
   18검으로 무너진 다리를 이어 민간인을 건너게 하고 수면 아래 검으로 적을 봉쇄한다.

4. **불타는 시장의 오십사검**  
   구조, 방어, 추격을 세 화면으로 교차한다.

5. **백팔인진 대 일인합격진**  
   108명의 인간 고수와 108검이 백야성 전체에서 충돌한다.

6. **백팔절명**  
   복수 루트. 책임자 108명에게 검 한 자루씩 배정한다.

7. **검의 그늘**  
   수호 루트. 72검으로 화살과 잔해를 막고 36검으로 탈출로를 만든다.

8. **검 아래의 평화**  
   군림 루트. 죽이지 않고 모든 수장 위에 검을 멈춰 세운다.

9. **일인합격진**  
   진상 루트. 12개 전장에서 서로 다른 임무를 동시 수행한다.

10. **한 자루의 마지막 검**  
    108검이 전장을 고정한 상태에서 이연이 무명검을 직접 들어 마지막 책임을 진다.

## 9. 비주얼·오디오 방향

### 화면 언어

- 이연의 몸동작은 작고 절제
- 검진의 변화는 크고 기하학적
- 난전보다 정렬과 정지가 위압적
- 원경에서 군진, 근경에서 칼날과 손동작
- 비, 검은 철, 젖은 돌, 낡은 목재, 붉은 등불
- 기능 강조색과 세계관 장식색 분리

### 소리

- 검관 바퀴
- 쇠사슬 당기는 소리
- 12개 잠금의 순차 해제
- 검이 부유할 때의 낮은 금속 공명
- 검대마다 다른 리듬
- 108검 전개 직전 의도적 정적
- 대규모 타격보다 정확한 절단·충돌 소리

## 10. 접근성·편의

- 읽은 문장 스킵
- 전체 장면 스킵과 전투 재생 분리
- 자동 진행 속도
- 텍스트 크기
- 배경 대비
- 화면 흔들림 강도
- 섬광 강도
- 검 궤적 표시 강도
- QTE 없음
- 전술 선택 시간 제한 기본 OFF
- 색상 외 문양·선·텍스트로 검대 구분
- 전투 결과 이유 표시
- 챕터·전술 선택 재시작

## 11. 저장

- 자동 저장: 장면 진입, 전술 선택 직전, 전투 결과 뒤
- 수동 슬롯: 출시 범위에서 제공
- 퀵 세이브/로드
- 글로벌 데이터: 본 문장, 엔딩, 검흔록, 옵션
- 슬롯 데이터: 루트, 장면, 플래그, 인물 상태, 전투 결과
- 저장 스키마 버전 필수
- 콘텐츠 ID 변경 시 마이그레이션 또는 명시적 호환 중단 기록

## 14. 미결정

- 최종 2D 캐릭터 표현 방식: 일러스트 스탠딩 / 3D 렌더 스틸
- 최종 음성 범위
- 게임패드 출시 필수 여부
- 전투 시네마틱 수동 카메라 허용 여부
- 검대 네이밍 최종안
- 한국어 외 첫 현지화 언어
- 최종 가격과 유통 채널

이 항목은 핵심 프로토타입과 자산 예산 뒤 결정한다.
