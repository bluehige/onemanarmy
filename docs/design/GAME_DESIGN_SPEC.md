# GAME DESIGN SPEC

> 상태: `CANONICAL DRAFT`  
> 장르 기준: `docs/foundation/VISUAL_NOVEL_CORE_CONTRACT.md`

## 1. 제품 개요

| 항목 | 정의 |
|---|---|
| 작업명 | 일인합격진: 검관을 끄는 남자 |
| 장르 | 하드보일드 무협 다회차 비주얼 노블 |
| 엔진 | Godot 4.6.3 |
| 플랫폼 | Windows PC |
| 화면 | 2D/2.5D 서사 화면 + 선택 뒤 재생되는 검진 시네마틱 |
| 입력 | 마우스·키보드, 게임패드 대응 |
| 핵심 상품 | 압도적인 108검 연출과, 그 힘을 어떤 원칙으로 사용할지 선택하는 서사 |

## 2. 장르 비중

```text
대화·선택·인물 관계·다회차 서사  75~80%
비실패형 감정 인터랙션           10~15%
검진 시네마틱·후일담             10~15%
수동 전투·전술 배치               0%
```

## 3. 캠페인 구조

```text
프롤로그
→ 공통부 5장
→ 계약 / 복수 / 수호 / 군림 중 한 루트
→ 엔딩
→ 읽은 문장 스킵·새 장면·검흔록 해금
→ 다른 루트
→ 주요 엔딩 3개 이상
→ 진상 루트
```

목표 분량은 수직 슬라이스 검증 후 재산정한다.

- 첫 엔딩: 6~8시간
- 전체: 20~28시간
- 공통 재사용 콘텐츠: 전체 신규 콘텐츠의 25% 이하

## 4. 핵심 플레이 루프

### 4.1 읽기

- 인물의 요구, 거짓말, 계약, 비용을 파악한다.
- 장면의 핵심 질문을 이해한다.
- 이연은 명백한 사실을 놓쳐 플롯을 늘리지 않는다.

### 4.2 관찰

`FOCUS_POINT`가 있는 장면에서는 2~4개의 지점 중 하나를 먼저 본다.

- 선택한 시선에 따라 내부 판단·질문 순서·짧은 단서가 달라진다.
- 필수 정보를 숨기거나 실패시키지 않는다.

### 4.3 결정

플레이어는 이연이 어떤 결과를 우선할지 선택한다.

예:

- 추적: 배후 정보를 얻고 부상 위험을 감수
- 수호: 사람을 지키고 도주자를 놓침
- 봉쇄: 적을 모두 남기지만 힘을 공개하고 공간 피해를 감수

### 4.4 결의 인터랙션

선택 뒤 `HOLD_INTENT` 또는 `CHAIN_PULL`을 1회 사용한다.

- 실패·점수·정확도 판정 없음
- 이연의 쇠사슬과 검의 미세한 정렬로 감정적 정적을 만든다.

### 4.5 검진 시네마틱

선택 ID에 대응하는 미리 저작된 시네마틱을 재생한다.

- 검의 역할과 공간 관계가 읽혀야 한다.
- UI는 거의 사라진다.
- 플레이어는 중간에 전투 명령을 내리지 않는다.

### 4.6 후일담

- 사람의 생존·부상
- 얻거나 놓친 정보
- 공간 피해
- 세력 반응
- 검 회수
- 다음 장면과 회차 상태

`AFTERMATH_INSPECT`와 `BLADE_RECALL`은 결과를 체감시키는 선택적 짧은 입력이다.

## 5. 선택 설계

### 좋은 선택

- 어느 선택도 이연을 무능하게 만들지 않는다.
- 직접 결과와 포기되는 결과를 이해할 수 있다.
- 다음 장면과 다른 회차가 기억한다.
- 선행/악행 버튼이 아니라 원칙 차이를 표현한다.
- 시네마틱과 후일담이 실제로 달라진다.

### 금지 선택

- 확률을 숨기고 인물을 죽이는 선택
- 대사 한두 줄만 바뀌는 선택
- 호감도 정답
- 입력 속도로 성공 여부가 결정되는 선택
- 플레이어가 검대·좌표·목표를 수동 배치하는 선택

## 6. 인터랙션 시스템

프로젝트는 다음 여섯 타입만 사용한다.

| 타입 | 역할 |
|---|---|
| FOCUS_POINT | 이연이 무엇을 먼저 보는지 선택 |
| HOLD_INTENT | 결정을 내리기 전 정적 체감 |
| CHAIN_PULL | 검진 시네마틱 시작의 물리적 신호 |
| BLADE_RECALL | 모든 검을 회수하는 태도 체감 |
| AFTERMATH_INSPECT | 선택 뒤 남은 결과 확인 |
| WEIGHTED_CONFIRM | 되돌릴 수 없는 선택 확인 |

상세 규칙은 `INTERACTION_LANGUAGE.md`를 따른다.

## 7. 108검 설계

### 구조

- 총 108자루
- 12검대 × 9검
- 플레이어 관리 대상이 아니라 시네마틱 안의 시각적 문법

### 표현 규칙

- 첫 10분 안에 전체 전개
- 9검·18검·36검·54검·72검·108검의 규모 대비
- 공격 외에 차단, 구조, 운반, 봉쇄, 증언을 표현
- 이연의 미세한 손동작과 연결
- 검진이 끝난 뒤 회수 또는 현장에 남은 결과를 보여 줌

### 콘텐츠 단위

`FormationCinematic`은 다음을 가진다.

```yaml
id: ""
story_choice_id: ""
location: ""
sword_count: 9|18|36|54|72|108
visual_roles: []
lee_yeon_gesture: ""
shot_sequence: []
aftermath_state: []
replay_summary: ""
```

## 8. 진행과 보상

능력치 성장은 없다.

보상은 다음이다.

- 새로운 질문과 침묵 선택
- 인물의 숨은 목적
- 사건 연표
- 검주 기록
- 다른 검진 변형
- 다른 후일담
- 루트·엔딩 해금
- 이미 본 시네마틱 감상

## 9. 검흔록

부가 메뉴이며 필수 진행을 방해하지 않는다.

탭:

- Routes
- Characters
- Blades
- Timeline
- Cinematics

전술 배치 비교, 장비, 능력치, 검대 강화는 포함하지 않는다.

## 10. 주요 콘텐츠 목표

| 타입 | 출시 목표 |
|---|---:|
| 공통 챕터 | 5 |
| 원칙 루트 | 4 |
| 진상 루트 | 1 |
| 주요 선택 | 25~35 |
| 소규모 검진 시네마틱 | 8~12 |
| 대형 검진 시네마틱 | 5~7 |
| 비실패형 인터랙션 패턴 | 6 이하 |
| 주요 엔딩 | 5 |
| 단기 엔딩 | 4~6 |

## 11. 대표 세트피스

1. 관천협의 108검 — 피난민 길과 기병 저지
2. 객잔의 구검 — 9검 정밀 제압
3. 빗속의 검교 — 이동·구조
4. 불타는 시장의 오십사검 — 세 결과 중 선택
5. 백팔인진 대 일인합격진 — 인간 진법과 검진의 대비
6. 백팔절명 — 복수 루트
7. 검의 그늘 — 수호 루트
8. 검 아래의 평화 — 군림 루트
9. 최종 일인합격진 — 진상 루트
10. 한 자루의 마지막 검 — 개인적 책임

모든 세트피스는 조작 가능한 전투가 아니라 선택 뒤 재생되는 서사 시네마틱이다.

## 13. 접근성

- 텍스트 크기
- 자동 진행
- 읽은 문장 스킵
- 인터랙션 자동 완료
- 길게 누르기 ↔ 토글
- 드래그 ↔ 단일 키
- 모션 감소
- 섬광 감소
- 화면 흔들림 0
- 시네마틱 전체 재생·요약·스킵

## 14. 분석 상태

내부 상태값은 서사 분기에 사용하지만 점수로 노출하지 않는다.

- contract
- vengeance
- protection
- dominion
- truth
- character states
- evidence states
- exposure
- damage
- seen text / seen cinematic / completed interaction

## 15. MVP 완료 기준

- 플레이 시작 10분 안에 108검 상품성 확인
- 비주얼 노블 흐름이 전술 화면으로 끊기지 않음
- 인터랙션 실패 0
- 7명 중 5명 이상이 이연의 결의 체감에 도움이 됐다고 응답
- 7명 중 4명 이상이 다른 선택 결과 재생 의향
- 이연이 약해 보였다는 반복 지적 없음
- 108검 시네마틱을 요약 버전으로도 이해 가능
