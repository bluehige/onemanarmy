# UI / UX SPEC

> 상태: `CANONICAL DRAFT`  
> 장르: 하드보일드 무협 비주얼 노블  
> 시각 기준: `docs/art/06_CANONICAL_VISUAL_STYLE_PROMPT.md`

## 1. UI 목표

UI는 플레이어가 이연의 시선, 선택과 결과를 이해하도록 돕는다.

> 지금 이연은 무엇을 보고, 어떤 원칙을 선택하며, 그 선택 뒤 무엇을 감당하는가?

UI는 검 108개를 관리하거나 전투를 조작하게 하지 않는다.

## 2. 화면 비중

```text
Story: 인물·배경 65~80%
Focus Interlude: 실제 장면 80% 이상
Choice / Intent: 실제 장면 70% 이상
Formation Cinematic: 시네마틱 90% 이상
Consequence: 후일담 이미지 55~70%
```

## 3. 화면 흐름

```text
S00 Title
→ S01 Story
→ 선택적 S02 Focus Interlude
→ S03 Narrative Choice / Intent
→ S04 Formation Cinematic
→ S05 Consequence
→ S01 Story
```

보조 화면:

```text
S06 Sword Trace Archive
S07 Save / Load
S08 Settings / Accessibility
S09 Chapter / Ending Select
```

## 4. 화면 계약

### S00 — Title

- 질문: 계속할 것인가, 새로 시작할 것인가
- P0: Continue, New Game
- P1: Load, Sword Trace Archive
- P2: Settings, Credits, Quit
- 저장이 있으면 Continue를 첫 포커스로 둔다.

### S01 — Story

- 질문: 누구의 말을 믿고 무엇을 묻거나 선택할 것인가
- P0: 화자, 본문, 진행 표시
- P1: 선택지
- P2: 로그, 자동, 읽은 문장 스킵, 저장
- 배경과 캐릭터가 화면의 중심이다.
- 상시 목표·검대·체력 HUD 없음
- 대화창은 하단 25~30%, 검 움직임이 하단에 있으면 18%로 축소 또는 숨김

### S02 — Focus Interlude

- 질문: 이연이 무엇을 먼저 보는가
- 입력: 장면 위 2~4개 포커스 지점 선택
- P0: 실제 장면, 포커스 윤곽, 한 줄 안내
- P1: 선택한 지점의 짧은 내부 판단
- P2: 추가 관찰
- 별도 지도, 검대 목록, 목표 슬롯 없음
- 한 지점만 봐도 진행할 수 있다.

### S03 — Narrative Choice / Intent

- 질문: 어떤 결과를 우선할 것인가
- P0: 2~4개의 서사 선택과 직접 대가
- 선택 후 `HOLD_INTENT` 또는 `CHAIN_PULL`이 짧게 나타날 수 있다.
- 선택지는 텍스트로 명확히 제시한다.
- 입력 숙련은 결과를 바꾸지 않는다.
- 되돌릴 수 없는 선택에만 `WEIGHTED_CONFIRM`을 사용한다.

### S04 — Formation Cinematic

- 질문: 선택이 어떻게 실행되고 있는가
- P0: 시네마틱 자체
- P1: 시작 2초의 핵심 목적
- P2: 일시정지, 전체 재생, 요약, 건너뛰기
- HP, 대미지, 콤보, 스킬바, 전술 명령 없음
- 이미 본 장면은 전체 재생 / 요약 / 결과 이동 선택 가능

### S05 — Consequence

- 질문: 무엇을 얻고 무엇을 잃었는가
- 한 장의 후일담 이미지
- 최대 네 줄의 결과 문장
- 검 회수 상태
- 선택적 `AFTERMATH_INSPECT`와 `BLADE_RECALL`
- 성공·실패·랭크·경험치 없음

### S06 — Sword Trace Archive

탭:

- Routes
- Characters
- Blades
- Timeline
- Cinematics

포함하지 않음:

- 전투 배치 비교
- 검대 덱
- 장비·능력치
- 강화·성장

### S07 — Save / Load

- 챕터, 장면, 루트, 시간, 스크린샷
- 자동 저장과 수동 저장 구분
- 중요한 선택 직전 자동 저장
- 호환 불가 저장의 이유 표시

### S08 — Settings / Accessibility

- 텍스트 크기
- 자동 진행 속도
- 읽은 문장 스킵 범위
- 인터랙션 안내
- 길게 누르기 ↔ 토글
- 드래그 ↔ 단일 키
- 인터랙션 자동 완료
- 시네마틱 전체/요약/스킵 기본값
- 모션 감소
- 섬광과 화면 흔들림
- 검 궤적 강도
- 음성·효과·음악
- 키 리매핑

### S09 — Chapter / Ending Select

- 읽은 챕터만 접근
- 루트별 핵심 분기와 엔딩
- 진상 루트 조건은 기록 범주로 표시
- 이전 회차의 인터랙션은 자동 완료 가능

## 5. CH01 화면

### 객잔 관찰

```text
실제 객잔 화면
+ 창문 / 등불 / 행상인의 손에 작은 포커스 인장
+ 하단 한 줄: "무엇을 먼저 본다"
```

### 추적 / 수호 / 봉쇄 선택

```text
[도주자를 추적한다]
배후 정보를 얻을 수 있다. 객잔 내부 부상 위험이 남는다.

[사람들을 지킨다]
객잔 사람은 무사하다. 도주자는 놓친다.

[객잔 전체를 봉쇄한다]
적을 모두 남긴다. 이연의 힘과 공간 피해가 커진다.
```

선택 카드나 전략 패널 대신, 기존 대화창 위에 선택지 세 줄을 표시한다.

### 결의 인터랙션

```text
쇠사슬을 쥔다
[누르고 있기 / 토글]
```

게이지 대신 쇠사슬 장력, 음향 감쇠와 검의 미세 정렬로 진행을 보여 준다.

### 결과

```text
대표 후일담 이미지
선택한 원칙
사람의 결과
확보·놓친 정보
공간 피해
검 회수 9/9
```

## 6. 정보 계층

### P0 Persistent

- 대사 또는 현재 선택
- 입력 접수 상태
- 진행 가능 여부

### P1 Contextual

- 포커스 지점
- 선택의 직접 대가
- 치명적·되돌릴 수 없는 경고
- 시네마틱 요약 상태

### P2 On Demand

- 인물·세력·검주 상세
- 단서 원문
- 추가 관찰

### P3 Record

- 루트 맵
- 읽은 대사
- 시네마틱 감상
- 내부 디버그

## 7. 공식 시각 언어

프롬프트 후보 4를 따른다.

- 따뜻한 골회색 종이 바탕
- 강한 흑백 대비
- 얼굴·손·검·검관의 날카로운 펜선
- 옷자락·절벽·연기의 넓고 끊긴 마른 먹 붓질
- 제한된 회색 워시
- 여백을 적극적으로 사용
- 마른 혈색 3~5% 이하

### 포인트 컬러

- 마른 혈색: 치명 경고, 되돌릴 수 없는 선택, 핵심 인장
- 탁한 청회색: 포커스와 비치명적 선택에 제한적으로 사용
- 금색: 작은 금속 반사 또는 인장만 허용

## 8. 컴포넌트 규칙

### 대화창

- 하단 25~30%
- 긴 본문은 가독성 높은 명조 또는 고딕
- 붓글씨는 장 제목과 짧은 표식에만 사용
- 큰 검 장식과 두꺼운 금장 프레임 금지

### 선택지

- 본문 위 세로 배열
- 2~4개
- 선택 결과를 한 문장으로 설명
- hover, focus, selected, disabled 상태
- 색 외에 코등이 모양, 윤곽, 위치 변화 사용

### 포커스 지점

- 작은 인장 또는 얇은 먹선 윤곽
- 실제 대상보다 크게 클릭 가능한 영역
- 선택 후 짧은 문장과 금속음
- 필수 정보를 색 하나로 표시하지 않음

### 누르기·당기기

- 큰 원형 QTE 게이지 금지
- 쇠사슬과 붓선의 변화로 진행 표시
- 대체 단일 키 제공

### 결과 화면

- 패널 여러 개를 겹치지 않음
- 후일담 이미지가 먼저 설명
- 최대 네 줄
- 상세 기록은 검흔록으로 분리

## 9. Hygiene Gate

다음은 즉시 FAIL이다.

- 대화 화면을 전술 대시보드가 가림
- 진행하려면 마우스 정밀 드래그가 필요
- 인터랙션 실패로 장면 중단
- 지원 입력 중 하나로 진행 불가
- 색 하나만으로 치명 결과 전달
- 보이는 대상과 클릭 영역 불일치
- 시네마틱 스킵 후 결과를 이해할 수 없음
- 읽지 않은 대사가 스킵됨
- 포커스 지점을 모두 찾아야 진행

## 10. 검증

- E0: 화면 계약과 데이터 검사
- E1: 상태별 정적 캡처
- E2: 실제 Godot 렌더
- E3: 마우스·키보드·게임패드 완주
- E4: 무설명 사용자 테스트

E4에서 확인할 것:

- 비주얼 노블로 느껴지는가
- 인터랙션이 이연의 감정을 보강하는가
- 미니게임처럼 느껴지는가
- 선택의 대가를 이해했는가
- 시네마틱 뒤 결과가 기억되는가
