# UI / UX SPEC

## 1. 프로젝트 UI 목표

UI의 역할은 108개의 검을 관리하는 복잡성을 늘리는 것이 아니라, 플레이어가 다음 질문에 빠르게 답하게 하는 것이다.

> 지금 이연의 검대를 어디에 배치해야 내가 원하는 승리를 얻는가?

### 감정 목표

- 서사 화면: 절제, 긴장, 무게
- 상단전 시야: 차갑고 명료한 통제
- 검진 집행: UI가 물러나고 시네마틱이 지배
- 결과 화면: 화려한 점수보다 선택의 가격

### 금지 마찰

- 108개 개별 검 선택
- 작은 아이콘 12개를 외워야 하는 구조
- 화면 가장자리에 지속되는 다수 게이지
- HP·MP·쿨다운 중심 HUD
- 목표와 검대 역할을 오직 색으로 구분
- 대화창이 검진의 핵심 화면을 가림
- 전술 선택과 실제 결과의 용어 불일치
- 애니메이션 중 입력 접수 여부 불명확

## 2. 화면 흐름

```text
S00 Title
→ S01 Story
→ S02 Upper-Dantian View
→ S03 Formation Confirm
→ S04 Cinematic Execution
→ S05 Consequence
→ S01 Story
```

보조 화면:

```text
S06 Sword Trace Archive
S07 Save / Load
S08 Settings / Accessibility
S09 Chapter / Ending Select
```

## 3. 화면 계약

### S00 — Title

- `player_question`: 계속할 것인가, 새로 시작할 것인가
- `primary_action`: Continue
- P0: Continue, New Game
- P1: Load, Sword Trace Archive
- P2: Settings, Credits, Quit
- 상태: 첫 실행 / 저장 있음 / 엔딩 후
- 규칙: 저장이 있으면 Continue를 첫 포커스로 둠

### S01 — Story

- `player_question`: 이 상황에서 누구의 요구를 받아들이고 무엇을 확인할 것인가
- `primary_action`: 대사 진행 또는 선택
- P0: 화자, 본문, 진행 표시
- P1: 선택지, 장면 목표
- P2: 로그, 자동, 스킵, 저장
- P3: 챕터 ID, 디버그 상태
- 금지: 상시 12검대 HUD
- 연출: 대화창은 하단 30% 내외, 중요한 전투 컷에서는 자동 축소 또는 숨김

### S02 — Upper-Dantian View

- `player_question`: 어떤 검대를 어느 목표에 배치할 것인가
- `primary_action`: 검대 토큰을 목표 슬롯에 할당
- P0: 핵심 목표, 사용 가능 검대, 현재 배치, 충돌
- P1: 부가 목표, 예상 직접 결과
- P2: 검대 상세, 과거 사용 예시
- P3: 내부 수치, 디버그 경로
- 의도된 도전: 목표 우선순위와 검대 역할 판단
- 금지 마찰: 역할 암기, 드래그 정밀도, 숨은 실패 조건

### S03 — Formation Confirm

- `player_question`: 이 배치와 예상 대가를 확정할 것인가
- `primary_action`: 집행
- P0: 목표별 배치, 예상 직접 결과, 미배치 위험
- P1: 변경, 초기화
- 파괴적 선택: 즉시 처형 명령은 문장으로 한 번 더 명확히 표시
- 전술 시간 제한이 있는 장면도 기본 설정에서는 멈춤 가능

### S04 — Cinematic Execution

- `player_question`: 선택한 명령이 어떻게 집행되고 있는가
- `primary_action`: 관람, 필요 시 다음 명령
- P0: 현재 핵심 목표 상태
- P1: 다음 판단이 발생하면 명확한 정지 신호
- P2: 일시정지, 재생 속도, 스킵
- 금지: 숫자 대미지, 적 체력바, 화면 중앙을 가리는 성공 문구
- 이미 본 시네마틱: 전체 재생 / 요약 / 결과로 이동

### S05 — Consequence

- `player_question`: 무엇을 얻고 무엇을 잃었는가
- `primary_action`: 결과 확인 후 계속
- P0: 핵심 목표 결과, 생존·사망, 계약 변화
- P1: 증거, 검 회수, 세력 반응
- P2: 상세 인과, 검흔록 갱신
- 금지: 점수 한 줄로 윤리 결과를 환산

### S06 — Sword Trace Archive

- `player_question`: 지금까지 어떤 선택과 검의 기록을 확인할 것인가
- `primary_action`: 루트·검대·검주 기록 탐색
- 탭: Route / Formations / Blades / Characters / Battle Replay
- 미확인 항목: 스포일러 텍스트 없이 빈 윤곽
- 12검대는 한 화면에 보이되 역할명과 문양을 함께 제공

### S07 — Save / Load

- 슬롯에 챕터, 장면, 루트, 시간, 스크린샷 표시
- 자동 저장과 수동 저장 구분
- 현재 선택 직전 자동 저장 제공
- 덮어쓰기 확인
- 호환 불가 저장은 이유와 가능한 복구 설명

### S08 — Settings / Accessibility

- 텍스트 크기
- 자동 진행 속도
- 읽은 문장 스킵 범위
- 시네마틱 스킵 방식
- 화면 흔들림
- 섬광
- 검 궤적 강도
- 음성·효과·음악
- 전술 시간 제한
- 게임패드 진동
- 키 리매핑

### S09 — Chapter / Ending Select

- 엔딩 후 해금
- 읽은 챕터만 접근
- 루트별 핵심 분기와 엔딩 표시
- 진상 루트 조건은 노골적인 스포일러 대신 필요한 기록 범주를 표시

## 4. 상단전 시야 레이아웃

### 데스크톱 16:9

```text
┌────────────────────────────────────────────────────┐
│ [핵심 목표] [남은 부가 목표]             [도움말] │
├──────────────┬───────────────────────┬─────────────┤
│ 검대 목록     │ 전장/목표 공간         │ 선택 상세    │
│ 3~6개 우선    │ 목표 슬롯과 예상 경로   │ 역할          │
│ 나머지 접기   │ 충돌·위험 표시          │ 직접 결과      │
├──────────────┴───────────────────────┴─────────────┤
│ [초기화] [이전]      미배치 위험 문장      [집행] │
└────────────────────────────────────────────────────┘
```

### 핵심 규칙

- 검대는 카드보다 `문양 + 9검 실루엣 + 역할 동사`로 표시
- 드래그와 클릭-대상 선택을 모두 지원
- 키보드/게임패드는 검대 → 목표 → 명령 순의 예측 가능한 포커스
- 배치 즉시 전장에 예상 경로를 표시
- 충돌은 붉은 색뿐 아니라 선 교차, 경고 아이콘, 문장으로 표시
- `집행` 버튼은 미배치 핵심 목표가 있으면 비활성 이유 표시
- 부가 목표 포기는 허용하되 결과를 명시

## 5. 정보 계층

### P0 Persistent

- 현재 장면의 핵심 질문
- 대사 본문 또는 핵심 전투 목표
- 현재 선택
- 입력 접수 상태
- 진행 가능 여부

### P1 Contextual

- 검대 역할
- 목표 충돌
- 부가 목표
- 인물 생존 경고
- 전투 중 다음 명령 시점

### P2 On Demand

- 검대 상세 설명
- 이전 사용 예시
- 세력 관계
- 장부·증거 원문
- 검주 기록

### P3 Record

- 전체 루트 맵
- 전투 비교
- 읽은 대사
- 내부 통계
- 개발 디버그

## 6. 디자인 시스템

### 색 역할

정확한 색상값은 실제 배경 테스트 뒤 확정한다.

- `bg_abyss`: 검은 먹색
- `surface_iron`: 차가운 철판
- `surface_paper`: 낡은 종이·골회색
- `text_primary`: 뼈색
- `text_muted`: 젖은 회색
- `accent_command`: 차가운 청백색
- `accent_lethal`: 마른 혈색
- `warning`: 탁한 황동
- `success`: 밝은 녹색 대신 안정된 청록 또는 문양
- `disabled`: 대비를 유지한 저채도

붉은색은 `죽임·돌이킬 수 없는 결과`에 우선 사용한다. 선택 상태 전체를 붉게 칠하지 않는다.

### 타이포 역할

- `hero`: 타이틀과 루트명
- `chapter`: 장 제목
- `speaker`: 화자
- `body`: 대사와 설명
- `command`: 전술 명령
- `support`: 보조 정보
- `record`: 검흔록 기록

한국어 본문은 장식 서체보다 장시간 가독성을 우선한다. 무협 서체는 제목·짧은 표식에만 제한한다.

### 형태

- 패널은 검관의 접철 구조를 연상시키되 과도한 금속 테두리 금지
- 선택 표식은 검 코등이 형태
- 목표 연결선은 검로처럼 날카롭되 충분한 두께
- 장식용 칼날은 버튼처럼 보이지 않게 함
- 모서리와 그림자는 세계관보다 정보 계층을 우선

### 모션

- 일반 UI 전환: 빠르고 절제
- 상단전 시야 진입: 주변 음향 감쇠, 선과 목표가 단계적으로 드러남
- 배치: 검대 실루엣이 목표 방향으로 정렬
- 충돌: 흔들림보다 경로 교차와 짧은 금속음
- 집행: UI가 검관 패널처럼 접히며 사라짐
- 결과: 점수 폭발 대신 남은 검과 빈 목표를 보여 줌

## 7. 입력

### 마우스

- 클릭 선택
- 드래그 배치
- 우클릭 취소
- 휠 로그/세부 스크롤
- 실제 hit 영역은 시각 영역보다 작지 않게

### 키보드

- Enter/Space 진행
- 숫자 또는 방향키 선택
- Tab 포커스 이동
- Esc 취소/메뉴
- Ctrl 읽은 문장 스킵
- L 로그
- A 자동
- 전술 화면 단축키는 튜토리얼 뒤 제공

### 게임패드

- 방향키/스틱 포커스
- A 확정
- B 취소
- 범퍼로 검대/목표 영역 전환
- 트리거로 세부 정보
- 포커스가 모달 밖으로 누출되지 않음

## 8. 접근성

- 텍스트 100/125/150%
- UI 스케일
- 색각에 관계없는 문양
- 화면 흔들림 0~100%
- 섬광 감소
- 검 궤적 두께·잔상 강도
- 자동 진행 최소/최대
- 음성 없는 정보는 텍스트
- 소리 신호에는 시각 표시
- 전술 시간 제한 OFF
- 시네마틱 중 중요 대사 자막
- 게임패드 진동 OFF
- 홀드 입력 대체

## 9. Hygiene Gate

다음 중 하나라도 있으면 FAIL이다.

- 읽을 수 없는 대사
- 핵심 목표가 화면에서 누락
- 검대 역할과 실제 결과 불일치
- 배치 입력 접수 피드백 없음
- 지원 입력으로 진행 불가
- 게임패드 포커스 단절
- 붉은색만으로 처형/경고 구분
- 시네마틱이 핵심 목표를 지속적으로 가림
- 미배치 이유 없이 집행 버튼 비활성
- 결과 화면이 선택과 결과의 인과를 설명하지 않음
- 읽은 문장 스킵이 읽지 않은 신규 장면까지 넘김

## 10. 검증 매트릭스

| 수준 | 증거 |
|---|---|
| E0 | 화면 계약, 상태표, 데이터 경로, 정적 검사 |
| E1 | 모든 상태의 정적 캡처 |
| E2 | 실제 Godot 렌더, 실제 대사 길이, 720p/1080p/울트라와이드 |
| E3 | 마우스·키보드·게임패드 완주, 포커스, 취소, 오류 복구 |
| E4 | 무설명 초회 사용자 테스트와 재플레이 관찰 |

구조적 목표:

- Hygiene 차단 결함 0
- GUX-Q8 80 이상
- 모든 차원 3점 이상
- 실제 UX 승인에는 E4 필수
