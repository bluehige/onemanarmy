## 1. 전역 원칙

- 장면의 기본 단위는 비주얼 노블 화면이다.
- 전술 지도, 검대 목록, 목표 슬롯, 전투 HUD를 사용하지 않는다.
- 인터랙션은 실제 배경 위에 작은 포커스 인장, 한 줄 안내, 쇠사슬 장력 변화로 표현한다.
- 검진 시네마틱이 시작되면 UI는 90% 이상 사라진다.
- 공식 스타일은 따뜻한 골회색 종이, 강한 흑백 대비, 날카로운 펜선, 넓고 끊긴 마른 먹 붓질, 제한된 마른 혈색이다.
- 캐릭터·검관·검 구조는 바이블이 우선이며 참고 이미지의 우연한 형태를 복제하지 않는다.

## 2. 화면 흐름

```text
VN Story
→ Focus Point가 있으면 실제 장면 위에서 짧게 선택
→ 일반 VN 선택지
→ 쇠사슬 Hold / Pull
→ 검진 시네마틱
→ 후일담 VN 화면
→ 결과 확인과 검 회수
```

# S01 — 백야성 입성

- 2D/2.5D VN 화면.
- 장 제목은 2초 후 사라진다.
- 문지기와 이연 스탠딩은 최대 2명.
- 아이가 검관에 다가가는 행동을 보일 때 대화창을 축소한다.
- 북문 종소리가 장면의 마지막 신호다.
- 상단 목표 목록이나 퀘스트 HUD 없음.

# S03 — 청우객잔 도착

- 객잔 외부와 마당을 넓게 보여 검관 위치를 기억하게 한다.
- 카메라가 객잔 안으로 들어가며 정문·창문·계단·주방·후문을 한 번씩 보여 준다.
- 공간 소개는 미장센이며 클릭 가능한 전술 지도가 아니다.

# S04 — 물 한 잔

- 이연은 출구가 보이는 자리에서 따뜻한 물을 주문한다.
- 적의 도발 대사는 길게 반복하지 않는다.
- 홍련이 쪽지를 떨어뜨리는 손을 의미심장하게 과장하지 않는다.

### FOCUS_POINT

실제 객잔 화면 위 다음 세 지점에 작은 인장을 표시한다.

- 창문 그림자
- 흔들리는 등불
- 행상인의 손

한 지점을 고르면 내부 판단 한 줄이 나온다. 추가 두 지점은 선택적으로 볼 수 있으나 진행에 필요하지 않다.

# S06 — 추적 / 수호 / 봉쇄

별도 상단전 전술 화면을 만들지 않는다.

실제 객잔 장면을 유지한 채 대화창 위에 선택지 세 개를 표시한다.

```text
도주자를 추적한다
배후 정보를 얻는다. 객잔 내부의 부상 위험이 남는다.

사람들을 지킨다
곽노삼과 복칠을 먼저 지킨다. 도주자는 놓친다.

객잔 전체를 봉쇄한다
적을 모두 남긴다. 힘의 노출과 공간 피해가 커진다.
```

선택 뒤 `결정을 거두지 않는다` 누르기 입력.

- 큰 원형 게이지 없음
- 쇠사슬이 팽팽해지고 음향이 가라앉음
- 검 9자루가 선택별 방향으로 미세하게 정렬
- 완료 뒤 즉시 시네마틱

# S08 — 후일담과 검 회수

결과별 2D 배경 변형:

- 추적: 묶인 도주자, 붕대, 경미한 손상
- 수호: 온전한 객잔, 열린 창문, 홍련
- 봉쇄: 그을린 들보, 검 자국, 창밖 군중

### AFTERMATH_INSPECT

1~3개의 흔적 중 하나를 선택한다. 모두 보지 않아도 진행한다.

### BLADE_RECALL

`검을 거둔다` 입력. 3개씩 세 차례 귀환. 마지막 검이 들어갈 때 잠금과 이연의 시선을 강조한다.

### 결과 화면

- 후일담 이미지 60% 이상
- 선택한 원칙
- 사람의 결과
- 확보·놓친 정보
- 공간 피해
- 검 회수 9/9
- 성공/실패 등급 없음

# S09 — 북문으로 향하는 길

- 결과별 생존 인물 한 명이 함정임을 지적한다.
- 이연이 쇠사슬을 손목에 감는다.
- `돈을 받았어.` 이후 조건별 한 문장.
- 북문 방향으로 걷는 이연과 검관의 후면 CG.
- 챕터 종료 카드.

## 완료 게이트

- 비주얼 노블 화면이 전체 플레이의 중심이다.
- 상단전 전술 화면, 검대 배치, 목표 슬롯이 없다.
- 인터랙션은 모두 20초 이내이며 실패가 없다.
- 선택을 하기 전에 결과와 대가를 읽을 수 있다.
- 시네마틱은 선택을 확대하고, 플레이어 입력 숙련을 평가하지 않는다.
- 세 결과는 대사 없이도 배경과 인물 상태로 구분된다.
- 공식 프롬프트 04 스타일을 유지한다.
