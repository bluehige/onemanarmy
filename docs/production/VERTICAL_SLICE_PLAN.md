# VERTICAL SLICE PLAN

> 상태: `CANONICAL DRAFT`  
> 장르: 비주얼 노블 중심  
> 전투·전술 배치: 포함하지 않음

## 1. 목적

45~60분짜리 CH01을 통해 다음을 검증한다.

1. 첫 10분 안에 이연과 108검이 구매 이유가 되는가
2. 대화와 선택이 플레이의 중심으로 느껴지는가
3. 짧은 비실패형 인터랙션이 이연의 심정을 보강하는가
4. 108검 시네마틱이 이야기를 끊지 않고 선택을 확대하는가
5. 첫 결과 뒤 다른 선택을 보고 싶은가

## 2. 포함 범위

- 관천협 108검 콜드 오픈
- 백야성 입성
- 북문 계약과 질문 선택
- 청우객잔 대화
- 객잔의 구검
- 추적 / 수호 / 봉쇄 서사 선택
- 실패 없는 시선·쇠사슬·검 회수 인터랙션
- 선택별 검진 시네마틱
- 후일담 3종
- 챕터 종료와 다음 장 예고
- 기본 대화·로그·자동·읽은 문장 스킵
- 자동 저장
- 시네마틱 전체·요약·스킵
- 접근성 설정 최소 범위

## 3. 제외 범위

- 수동 전투
- 전술 지도와 검대 배치
- 목표 슬롯·사거리·전투 라운드
- HP·대미지·능력치
- 검대 덱·조합·강화
- 장비·인벤토리
- 오픈월드 백야성
- 전체 루트
- 전체 음성
- 온라인 기능

## 4. CH01 흐름

```text
S00 관천협
  FOCUS_POINT
  → 서사 선택 2개
  → HOLD_INTENT / CHAIN_PULL
  → 108검 시네마틱
  → BLADE_RECALL

S01 백야성 입성
→ S02 골목의 계약과 질문 선택
→ S03 청우객잔 도착
→ S04 객잔 관찰 FOCUS_POINT
→ S05 구검 자동 제압
→ S06 추적 / 수호 / 봉쇄 선택
  → HOLD_INTENT
  → 선택별 9검 시네마틱
→ S08 AFTERMATH_INSPECT / BLADE_RECALL
→ S09 북문으로 출발
```

## 5. 마일스톤

산출물:

- 비주얼 노블 핵심 계약
- 허용 인터랙션 목록
- 금지 전투 모듈 목록
- CH01 문서 정규화

완료:

- 모든 기준 문서가 수동 전투와 전술 배치를 금지
- 새 세션이 비주얼 노블 흐름을 설명 가능

### M3 — 검진 시네마틱

### M5 — CH01 통합

완료:

## 8. 플레이테스트 질문

- 이 게임을 어떤 장르로 느꼈는가
- 이연은 어떤 종류의 강자인가
- 108검은 어떻게 움직였다고 이해했는가
- 인터랙션이 이연의 감정을 이해하는 데 도움 됐는가
- 미니게임이나 전투처럼 느껴졌는가
- 이야기 흐름이 끊긴 순간은 어디인가
- 추적 / 수호 / 봉쇄에서 무엇을 포기했는지 설명할 수 있는가
- 다른 선택 결과를 보고 싶은가
- 이미 본 인터랙션은 자동 완료하고 싶은가

## 9. KEEP 기준

7명 기준:

- 5명 이상이 비주얼 노블로 인식
- 5명 이상이 이연을 `한 사람의 군진`으로 이해
- 5명 이상이 인터랙션이 결의 체감에 도움 됐다고 응답
- 2명 이하만 미니게임처럼 느꼈다고 응답
- 4명 이상이 다른 분기 재플레이
- 입력 실패 0명
- 이연이 약해 보였다는 반복 지적 1명 이하
- 첫 10분 108검 장면을 핵심 매력으로 지목 5명 이상

## 10. REDESIGN 원칙

문제가 생기면 다음 중 하나로 분리한다.

- 대사 템포
- 선택 정보
- 인터랙션 길이
- 시네마틱 길이
- 후일담 가독성
- 입력 접근성
- 성능

인터랙션 문제가 발생해도 수동 전투나 전술 배치로 확장하지 않는다. 필요하면 인터랙션을 단일 클릭 또는 자동 연출로 축소한다.
