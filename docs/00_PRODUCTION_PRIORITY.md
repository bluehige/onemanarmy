# 제작 우선순위 결정

> 상태: `CANONICAL`  
> 장르: 하드보일드 무협 다회차 비주얼 노블

## 결론

전체 장편 대본을 먼저 완성하지 않는다. 전투 시스템이나 광범위한 기술 뼈대도 먼저 만들지 않는다.

올바른 순서는 다음과 같다.

```text
비주얼 노블 핵심 계약 고정
→ CH01 대화·선택·감정 인터랙션 정규화
→ 108검 시네마틱 표현 검증
→ CH01 45~60분 MVP 구현
→ 실제 사용자 테스트
→ 전체 공통부와 루트 확장
```

## 현재 위험 가정

1. 첫 10분의 108검 시네마틱이 이연을 `한 사람의 군진`으로 보이게 하는가
2. 시선 선택·쇠사슬 누르기·검 회수가 미니게임이 아니라 이연의 심정으로 느껴지는가
3. 시네마틱이 비주얼 노블의 대화 템포를 끊지 않는가
4. 추적 / 수호 / 봉쇄의 결과와 대가가 화면에서 읽히는가
5. 다른 선택을 보기 위한 재플레이 동기가 생기는가

## P0 — 장르 재정규화

완료 조건:

- `VISUAL_NOVEL_CORE_CONTRACT.md`가 최상위 계약
- 수동 전투·전술 배치 금지
- 프로젝트 Skill 전체 갱신
- CH01 대본·콘티·UI·기술 문서 갱신
- 기존 BattleResolver·검대 배치 표현 폐기

## P1 — EXP-001 108검 시네마틱

검증 장면:

- 관천협
- FOCUS_POINT 1회
- 선택 2개
- HOLD_INTENT / CHAIN_PULL
- 108검 시네마틱 2변형
- BLADE_RECALL

만들지 않을 것:

- 전투 HUD
- 검대 배치
- 적 AI
- HP·대미지
- 전체 저장 시스템
- 최종 자산 전체

## P2 — EXP-002 감정 인터랙션

객잔 구간을 사용한다.

```text
관찰
→ 추적 / 수호 / 봉쇄 선택
→ 쇠사슬 누르기
→ 9검 시네마틱
→ 후일담 확인
→ 검 회수
```

판정할 것:

- 인터랙션이 감정을 보강하는가
- 비주얼 노블 흐름이 유지되는가
- 실패 걱정 없이 이해되는가
- 재플레이에서 자동 완료가 필요한가

## P3 — CH01 수직 슬라이스

구성:

- 관천협 108검
- 백야성 입성
- 골목의 북문 계약
- 청우객잔
- 객잔의 구검
- 추적 / 수호 / 봉쇄
- 결과와 북문 훅

목표 시간: 45~60분.

## P4 — CH01 사용자 테스트

E4 테스트 7명을 기본 표본으로 한다.

KEEP 기준:

- 5명 이상 비주얼 노블로 인식
- 5명 이상 이연을 `한 사람의 군진`으로 이해
- 5명 이상 인터랙션이 결의 체감에 도움
- 2명 이하만 미니게임처럼 느낌
- 4명 이상 다른 선택 재플레이 의향
- 입력 실패 0

## P5 — 전체 제작

CH01 KEEP 뒤 다음 순서로 확장한다.

1. 공통 루트
2. 계약 루트
3. 수호 루트
4. 복수 루트
5. 군림 루트
6. 진상 루트

스토리 제작은 장면별로 다음을 함께 작성한다.

- 대화와 선택
- 선택적 포커스
- 감정 인터랙션
- 검진 시네마틱
- 후일담과 재플레이 정보
