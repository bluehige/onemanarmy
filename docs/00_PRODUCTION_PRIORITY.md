# 제작 우선순위 결정

## 결론

**전체 스토리를 먼저 완성하지 않는다. 기술 뼈대부터 무작정 만드는 것도 아니다.**

이 프로젝트의 올바른 순서는 다음과 같다.

```text
최소 서사 계약
→ 108검 표현·지휘 프로토타입
→ 실제 플레이 판정
→ 수직 슬라이스 GDD·기술 계약
→ 공통부와 한 개 루트 제작
→ 전체 다회차 시나리오 확장
```

이미 강한 주인공 콘셉트와 세계관의 중심 갈등은 확보됐다. 현재 가장 위험한 미확인 사항은 줄거리의 양이 아니라 다음 두 가지다.

1. 108자루가 화면에서 무작위 파티클이 아니라 **한 사람이 지휘하는 군진**으로 읽히는가.
2. 비주얼 노블 플레이어가 검대 배치와 결과를 이해하면서도 이야기의 흐름이 끊기지 않는가.

이 두 질문을 검증하지 않고 장편 시나리오를 먼저 쓰면, 나중에 전투 구조에 맞춰 장면을 대량 재작성하게 된다. 반대로 Godot 시스템 전체를 먼저 만들면, 아직 검증되지 않은 재미 가정을 제품 아키텍처로 굳히게 된다.

## 단계별 순서

### P0 — 게임 계약 고정

현재 문서 초안이 해당한다.

고정할 것:

- 플레이어 판타지
- 이연의 능력과 약점이 아닌 운영 제약
- 12검대 × 9검 구조
- 전투의 질문
- 하드보일드 톤
- 네 개의 원칙 루트
- 금지 구조
- 프로토타입 성공·재설계·폐기 기준

완료 게이트:

- 기능 하나를 제안했을 때 어느 기둥을 강화하는지 설명 가능
- 이연을 약하게 만들어 긴장감을 만드는 제안이 차단됨
- 108검을 첫 장면부터 보여 주는 것이 확정됨
- 전체 시나리오 없이도 `EXP-001`을 만들 수 있음

### P1 — EXP-001: 108검 표현 검증

가장 먼저 만들 실제 Godot 결과물이다.

필수 장면:

1. 검관의 12개 잠금이 순차 해제
2. 9검 → 36검 → 108검 단계 전개
3. 108검이 12개 검대로 정렬
4. 이연의 작은 손동작으로 진형 전체가 전환
5. 화살 차단, 기병 진로 변경, 지휘관 제압
6. 전투 뒤 모든 검이 검관으로 귀환

이 단계에서 만들지 않을 것:

- 전체 대화 시스템
- 전체 저장 시스템
- 최종 캐릭터 모델
- 장편 시나리오
- 모든 검진
- 모든 UI 화면
- 전체 백야성

판정 기준은 `docs/foundation/PROTOTYPE_BRIEF.md`를 따른다.

### P2 — EXP-002: 지휘 판단 검증

EXP-001에서 108검의 시각적 매력이 확인된 뒤 진행한다.

한 전투에서 플레이어에게 세 목표를 준다.

- 화살 차단
- 민간인 탈출로 확보
- 적 지휘관 생포

12검대 중 제한된 수를 각 목표에 배치하게 하고, 어떤 선택을 하더라도 이연은 전투에서 패배하지 않는다. 대신 누가 살아남고 어떤 증거를 얻는지가 바뀐다.

검증할 것:

- 플레이어가 검대 역할을 기억하지 않고 화면에서 인식할 수 있는가
- 결과가 선택과 연결됐다고 느끼는가
- 전술 화면이 시네마틱의 기대감을 높이는가
- 전투 후 서사 결과가 이해되는가

### P3 — 수직 슬라이스 계약

P1·P2의 결과를 반영해 다음을 확정한다.

- 전투당 라운드 수
- 검대 선택 방식
- 3D 시네마틱 길이
- 대화와 전투의 비율
- 카메라 언어
- 데이터 스키마
- 실제 성능 예산
- UI 화면 계약
- 테스트 경로

이 시점부터 기술 계획이 `planned`에서 `approved`로 이동한다.

### P4 — 45~60분 수직 슬라이스

구성:

- 프롤로그 `관천협의 108검`
- 백야성 입성
- 객잔의 구검
- 북문 계약
- 시장 화재 전투
- 계약/수호 중 한 번의 분기
- 결과 화면과 2회차 해금 예고

검증 목표:

- 108검이 첫 상품으로 작동하는가
- 이연이 대사보다 행동으로 매력적인가
- 전술 판단이 서사 흐름을 끊지 않는가
- 첫 결과 뒤 다른 선택을 보고 싶은가

### P5 — 전체 루트 제작

수직 슬라이스가 통과한 뒤에만 다음 순서로 확장한다.

1. 공통 루트
2. 계약 루트
3. 수호 루트
4. 복수 루트
5. 군림 루트
6. 세 개 이상 엔딩 완료 조건의 진상 루트

초기 제작 순서에서 계약·수호를 먼저 두는 이유는 동일한 전투 시스템으로 `봉쇄`와 `구조`라는 상반된 플레이를 검증할 수 있기 때문이다. 복수와 군림은 대규모 최종 연출 의존도가 높아 후순위다.

## 장편 스토리를 쓰기 전에 필요한 최소 서사

다음만 먼저 확정하면 된다.

- 사건의 발단
- 주요 인물 다섯 명의 욕망과 금기
- 공통부의 다섯 사건
- 네 루트가 답하는 윤리 질문
- 각 루트의 대표 108검 장면
- 진엔딩의 최종 선택과 대가

세부 대사, 모든 회상, 108명의 검주 기록은 프로토타입 통과 후 제작한다.
