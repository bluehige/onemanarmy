# 콘셉트 이미지 제작 큐

> 상태: `CANONICAL DRAFT`  
> 장르: 하드보일드 무협 다회차 비주얼 노블  
> 렌더링 기준: [`06_CANONICAL_VISUAL_STYLE_PROMPT.md`](06_CANONICAL_VISUAL_STYLE_PROMPT.md)

## 1. 제작 원칙

- 이연과 검관 기준을 먼저 확정한다.
- UI는 비주얼 노블의 인물·배경·대사를 우선한다.
- 이미지 한 장당 검증 질문 하나를 둔다.
- 검의 수보다 질서, 선택의 결과와 후일담을 우선한다.
- 참고 이미지에 보이는 상태창·장비·전술 지도는 실제 기능으로 사용하지 않는다.
- 멋있어도 공식 스토리·장르·구조와 충돌하면 `REVISE`다.
- 한 세션에서 기준 1종 → 구조 수정 2~3회 → 승인 후보 1종 순으로 진행한다.

## 2. 우선순위 A — 정체성 고정

### CA-001 이연 전신 키시트

**질문**  
이연이 평범한 검객이 아니라, 검관과 108검을 책임지는 완성형 해결사로 보이는가?

**필수**

- 36세의 성숙한 얼굴
- 정면·3/4·측면·후면
- 낮게 묶은 검은 머리
- 먹색 실용 무복
- 왼손 쇠사슬
- 허리 왼쪽 무명검 한 자루
- 곧은 자세
- 검관 크기 비교
- 얼굴 표정과 손동작 세부

**금지**

- 미소년, 노인, 광전사
- 사무라이·닌자
- 황금 갑옷
- 등에 여러 검 또는 원통 검통
- 힘겹게 검관을 끄는 자세

### CA-002 검관 구조 시트

**질문**  
검관이 낮고 긴 관형 수레이며 12검대 구조를 실제로 수납할 수 있는가?

**필수**

- 폐쇄 3/4
- 정면·측면·후면·평면
- 이연과 크기 비교
- 바퀴·쇠사슬·12잠금
- 9/36/72/108 개방 단계
- 내부 12검갑

**금지**

- 등에 메는 검통
- 전차형 실루엣
- 미래형 포드와 미사일 상자
- 마법 수납 공간

### CA-003 12검대 실루엣 시트

**질문**  
색을 제거해도 검대의 편대와 기능이 구분되는가?

**필수**

- 12개 대표검
- 12개의 9검 편대
- 동일 축척
- 이연 실루엣과 크기 비교
- 지휘검의 최소 차별화

**금지**

- 불·얼음·번개 속성화
- 색만 다른 동일 검
- 플레이어용 카드·등급·레벨 UI

## 3. 우선순위 B — 비주얼 노블 화면 고정

### UI-001 Story 화면

**질문**  
한눈에 하드보일드 무협 비주얼 노블로 보이는가?

**구도**

- 16:9
- 인물과 배경 70% 전후
- 하단 25~30% 대화창
- 화자명·본문·진행 표시
- 로그·자동·스킵·저장 보조 행

**필수**

- 프롬프트 04 골회색 종이와 고대비 먹선
- 실제 캐릭터 얼굴과 배경 우선
- 긴 한국어 본문을 위한 명확한 여백

**금지**

- HP·내력·레벨·장비·스킬
- 상단 목표 목록과 미니맵
- 전술 지도와 검대 목록
- 장식용 붓질이 버튼처럼 보이는 구성

### UI-002 Focus Interlude

**질문**  
전술 화면으로 바뀌지 않고도 이연의 시선을 플레이어가 체감하는가?

**구도**

- 실제 객잔 또는 골목 장면 유지
- 2~4개 대상에 얇은 먹선·작은 인장
- 하단 한 줄 안내
- 대상 선택 후 짧은 내부 판단 공간

**금지**

- 조사 퍼즐 목록
- 단서 체크리스트
- 전술 지도
- 모두 찾아야 진행되는 구조

### UI-003 Narrative Choice / Intent

**질문**  
선택의 결과와 대가를 읽은 뒤 이연의 결의를 손으로 느낄 수 있는가?

**구도**

- 일반 VN 선택지 2~4개
- 선택마다 직접 결과와 포기 결과 한 줄
- 선택 뒤 쇠사슬을 쥔 손 컷인
- 큰 진행 게이지 대신 체인 장력과 먹선 변화

**금지**

- QTE 링
- 타이밍 판정
- 성공률
- 전술 명령 카드와 목표 슬롯

### UI-004 Consequence 화면

**질문**  
선택 뒤 무엇을 얻고 잃었는지 점수 없이 이해되는가?

**구도**

- 후일담 이미지 60% 전후
- 결과 최대 네 줄
- 사람·정보·공간 피해·검 회수
- 계속 버튼

**금지**

- 랭크, 별점, 경험치
- 명성 수치
- 여러 패널이 결과 이미지를 가리는 구성

## 4. 우선순위 C — CH01 핵심 상품

### KF-001 관천협의 108검

**질문**  
이미지 한 장으로 `한 사람이 군진으로 길과 결과를 통제한다`는 상품이 읽히는가?

**구도**

- 21:9 또는 16:9 와이드
- 전경: 쇠사슬을 당기는 이연과 낮고 긴 검관
- 중경: 12검대로 분리된 108검
- 원경: 피난민과 방향이 막힌 기병대
- 협곡 전체 관계가 읽히는 3/4 원경

**필수**

- 화살 차단, 기병 진로 변경, 지휘관 봉쇄 또는 피난 통로
- 이연의 정적
- 진형이 잠긴 순간
- 공식 스토리 대상만 등장

**금지**

- 검비로 군대 몰살
- 한 목표를 향한 검 광선
- 검 날개 중심 초상
- 호랑이·괴수·스토리에 없는 동료
- 등에 메는 원통 검관

### KF-002 객잔의 구검

**질문**  
9검만으로 이연의 정밀함과 여유가 압도적인가?

**구도**

- 이연은 탁자 옆에 앉아 있거나 막 일어남
- 검관은 열린 문 밖
- 9검은 창문·기둥·계단·주방·인질·사수를 서로 다른 방식으로 제압
- 적은 죽은 것이 아니라 움직일 수 없는 상태

**금지**

- 검 9개 난사
- 과도한 유혈
- 코미디 난투
- 전투 HUD

### KF-003 골목의 계약

**질문**  
계약과 죽음의 무게가 설명보다 손과 소품으로 보이는가?

**구도**

- 젖은 손
- 청동 계약패
- 봉인 서찰통
- 조문탁과 이연의 거리
- 대화창 안전 영역

### KF-004 추적 후일담

- 생포된 도주자
- 곽노삼 어깨 붕대
- 복칠 경상
- 이연이 치료비를 책임지는 태도

### KF-005 수호 후일담

- 온전한 객잔
- 열린 창문과 도주 흔적
- 무사한 곽노삼·복칠
- 홍련과의 조용한 정보 교환

### KF-006 봉쇄 후일담

- 출구를 잇는 검 자국
- 그을린 들보
- 창밖 군중
- 힘의 공개와 공간 피해

### KF-007 북문으로 향하는 길

- 비 내리는 거리
- 이연과 검관의 후면 실루엣
- 멀리 닫힌 북문
- 챕터 종료 텍스트 안전 영역

## 5. 우선순위 D — 후속 대표 세트피스

### KF-008 빗속의 검교

- 검은 공격보다 구조와 이동에 사용
- 민간인이 실제로 검교를 건넘
- 이연은 검 위를 곡예하듯 날지 않음

### KF-009 불타는 시장의 오십사검

- 건물 지지, 민간인 이송, 증인 추적이라는 세 결과
- 실제 게임에서는 플레이어가 검대를 배치하지 않고 서사 선택 뒤 변형 시네마틱을 봄
- 각 변형은 별도 후일담을 가짐

### KF-010 백팔인진 대 일인합격진

- 인간 108명과 검 108자루의 질서 대비
- 난전 직전 진형이 잠기는 순간
- 사람을 도구로 쓰는 곽천도와 검을 책임으로 짊어진 이연의 차이

### KF-011 백팔절명

- 복수 루트
- 책임자 108명의 사각에 검 한 자루
- 처형 전 정지
- 마른 혈색은 결정 표시와 소량의 피에만 사용

### KF-012 검의 그늘

- 수호 루트
- 72검 방벽과 36검 탈출로
- 민간인이 실제로 이동

### KF-013 검 아래의 평화

- 군림 루트
- 각 세력 수장 위에 멈춘 검
- 싸움이 없는데 가장 위압적인 장면

### KF-014 최종 일인합격진

- 진상 루트
- 백야성 12구역의 서로 다른 결과
- 플레이어가 직접 배치하는 UI가 아니라 앞선 회차 선택이 시네마틱 변형을 결정

### KF-015 한 자루의 마지막 검

- 108검은 전장을 고정한 채 정지
- 이연이 무명검을 직접 뽑음
- 대규모 힘과 개인 책임의 대비

## 6. 제작 보조 이미지

- `ENV-001` 백야성 지도형 세계관 콘셉트 — 게임 내 전술 지도 아님
- `ENV-002` 객잔 내부 구조와 카메라 기준
- `ENV-003` 북문과 수로
- `ENV-004` 시장 전·후 상태
- `FX-001` 검 궤적·정지·회수 표현
- `UI-005` 쇠사슬 HOLD / PULL 피드백 시트
- `UI-006` AFTERMATH_INSPECT 인장 시트

## 7. 승인 상태

| 상태 | 의미 |
|---|---|
| DRAFT | 탐색, 기준으로 사용 금지 |
| REVISE | 일부 유지 가능, 수정 필요 |
| CANONICAL | 이후 이미지·UI·3D 제작 기준 |
| SUPERSEDED | 최신 기준으로 대체 |

## 8. 즉시 실행 순서

```text
1. CA-001 이연 기준 시트
2. CA-002 검관 구조 시트
3. CA-003 12검대 실루엣
4. UI-001 Story 화면
5. UI-002 Focus Interlude
6. UI-003 Narrative Choice / Intent
7. KF-001 관천협의 108검
8. KF-002 객잔의 구검
9. UI-004 Consequence 화면
```

각 단계는 공식 프롬프트 04 스타일, 비주얼 노블 장르 계약, 실제 장면 사실을 동시에 통과해야 한다.
