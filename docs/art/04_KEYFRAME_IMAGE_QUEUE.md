# 콘셉트 이미지 제작 큐

> 상태: `CANONICAL DRAFT`  
> 목적: 다음 이미지 생성 세션에서 무엇부터 만들고 어떤 기준으로 승인할지 고정

## 1. 제작 원칙

- 캐릭터와 검관 기준을 먼저 확정한다.
- 한 번에 여러 콘셉트를 섞지 않고 이미지 한 장당 질문 하나를 검증한다.
- 108검의 수보다 검대의 질서와 장면 목적을 우선한다.
- 생성 결과가 멋있어도 기준 문서와 충돌하면 `REVISE`다.
- 다음 이미지로 넘어가기 전에 유지할 요소와 변경할 요소를 기록한다.

## 2. 우선순위 A — 정체성 고정

### CA-001 이연 전신 키시트

**검증 질문**  
이연이 평범한 검객이 아니라 검관과 108검을 지휘하는 완성형 해결사로 보이는가?

**구도**

- 3:4 세로
- 정면 3/4 전신
- 이연 뒤에 폐쇄 상태 검관
- 중립적인 젖은 석벽 또는 회색 스튜디오 배경

**반드시 보일 것**

- 36세의 성숙한 얼굴
- 낮게 묶은 검은 머리
- 먹색 실용 무복
- 왼손의 검관 쇠사슬
- 허리의 무명검
- 곧은 자세와 통제감

**금지**

- 20대 미소년
- 황금 갑옷
- 등에 꽂은 여러 검
- 과장된 마법광
- 검관을 힘겹게 끄는 자세

**승인 후 고정할 것**

- 얼굴
- 머리 길이
- 체형
- 의상 실루엣
- 흉터 위치
- 무명검 위치

---

### CA-002 검관 구조 시트

**검증 질문**  
검관이 장례용 관의 무게와 12검대의 기능을 동시에 가진 독창적인 운반 장치로 보이는가?

**구도**

- 16:9 또는 가로형 설계 시트
- 폐쇄 상태 3/4
- 측면
- 4단계 개방
- 이연과 크기 비교 실루엣

**반드시 보일 것**

- 낮고 긴 관형 수레
- 흑철 프레임과 그을린 목재
- 넓은 바퀴 두 개
- 검은 쇠사슬
- 12개 잠금쇠
- 내부 12검갑

**금지**

- 미래형 무기 상자
- 미사일 포드
- 톱니바퀴 중심 스팀펑크
- 높은 전차형 실루엣

---

### CA-003 12검대 실루엣 시트

**검증 질문**  
색을 제거해도 검대의 기능과 편대가 구분되는가?

**구도**

- 밝은 중립 배경
- 12개 대표검과 9검 기본 편대
- 동일한 축척

**반드시 보일 것**

- 실루엣 차이
- 지휘검의 최소 차별화
- 역할에 맞는 편대

**금지**

- 검대별 불·얼음·번개 속성
- 판타지 무기 도감 같은 과장
- 색만 다른 동일 모델

## 3. 우선순위 B — 핵심 상품 검증

### KF-001 관천협의 108검

**검증 질문**  
첫 이미지 하나만 보고 “한 사람이 군대를 검진으로 통제한다”는 핵심 상품을 이해할 수 있는가?

**구도**

- 21:9 또는 16:9 와이드
- 전경: 쇠사슬을 가볍게 당기는 이연
- 중경: 12검대로 분리된 108검
- 원경: 진로가 막히고 방향을 잃은 기병대
- 협곡의 높이와 폭이 한눈에 보이는 3/4 원경

**반드시 보일 것**

- 108검 전체 전개
- 화살 차단, 기병 유도, 지휘관 포위의 서로 다른 역할
- 이연은 세 걸음 이상 움직이지 않은 듯한 정적
- 검진이 완성되어 잠긴 순간

**금지**

- 검비 한 번으로 군대 몰살
- 한 목표를 향한 검 광선
- 검 날개만 강조한 정면 초상
- 이연의 고통이나 과부하

**대표 잔상**

> 협곡의 모든 길이 검에 의해 다시 그려진 상태.

### KF-002 객잔의 구검

**검증 질문**  
108검을 전부 쓰지 않아도 이연의 정밀함과 태도가 압도적인가?

**구도**

- 16:9
- 이연은 탁자 옆에 앉거나 서서 술잔을 듦
- 9검은 창문, 바닥, 기둥, 계단에서 적을 고정
- 적 20명의 병기와 옷자락이 서로 다른 방식으로 봉쇄

**반드시 보일 것**

- 술잔을 내려놓지 않은 이연
- 죽이지 않고 끝난 정밀 제압
- 검관은 객잔 밖 또는 열린 문 너머
- 전투 후 남은 얇은 절단선

**금지**

- 공중에서 검 9개를 난사
- 적의 과도한 절단·유혈
- 코미디 난투

---

### KF-003 빗속의 검교

**검증 질문**  
이기어검이 공격뿐 아니라 이동·구조·지형 설계 능력으로 보이는가?

**구도**

- 21:9
- 폭우 속 끊어진 다리와 강
- 18검은 다리 구조를 보강
- 다른 18검은 화살 차단
- 이연은 검의 평면과 코등이를 순차적으로 밟아 건넘
- 민간인이 검교를 통해 이동

**반드시 보일 것**

- 검이 단순 공중 계단이 아니라 실제 하중과 방향을 계산한 구조
- 수면 아래 대기 중인 봉쇄검
- 빗물과 검신 반사

**금지**

- 이연이 구름을 타듯 부유
- 검이 빛나는 판자로 변함
- 곡예사형 과장 포즈

---

### KF-004 불타는 시장의 오십사검

**검증 질문**  
이연이 세 전장을 동시에 지휘하며 강함을 잃지 않는가?

**구도**

- 21:9 또는 2.39:1
- 중앙: 눈을 뜬 채 작은 명령을 내리는 이연
- 왼쪽: 27검이 붕괴 건물 지지
- 오른쪽: 18검이 민간인을 운반
- 후경: 9검이 납치범 추적

**반드시 보일 것**

- 각 검대의 목적이 분명한 세 구역
- 불과 연기 속에서도 검대 실루엣이 읽힘
- 이연은 고통보다 집중과 판단을 보임

**금지**

- 이연 주변만 화려하고 구조 장면이 묻힘
- 검이 물체를 폭발시켜 해결
- 민간인이 장식 군중으로만 표현

## 4. 우선순위 C — 대립과 루트 이미지

### KF-005 백팔인진 대 일인합격진

- 인간 고수 108명과 검 108자루의 질서가 대비되어야 함
- 사람을 도구로 쓰는 곽천도와 죽은 동료의 검을 책임지는 이연의 차이
- 양쪽이 난전으로 섞이기 전 진형이 잠기는 순간

### KF-006 백팔절명

- 복수 루트
- 108명의 책임자 각각의 사각에 검 한 자루
- 이연의 손가락 하나가 마지막 결정
- 처형 전 정지 상태를 대표 이미지로 사용

### KF-007 검의 그늘

- 수호 루트
- 72검이 성 위의 방벽
- 36검이 강 위의 탈출로
- 민간인이 실제로 검 위를 건너는 장면

### KF-008 검 아래의 평화

- 군림 루트
- 각 세력 수장 머리 위에 멈춘 검
- 이연은 왕좌가 아니라 종루나 성벽에 서 있음
- 싸움이 없는데도 가장 위압적인 이미지

### KF-009 최종 일인합격진

- 진상 루트
- 백야성 전역의 12개 전장
- 확대하면 검대별 임무, 축소하면 도시 전체의 하나의 진
- 이연은 도시 중앙이 아니라 전장을 볼 수 있는 종루에 위치

### KF-010 한 자루의 마지막 검

- 108검은 전장을 고정한 채 정지
- 이연이 무명검을 직접 뽑음
- 마지막 적과 짧은 거리를 걸어감
- 대규모 진법과 개인적인 책임의 대비

## 5. 우선순위 D — 제작 보조 이미지

- `ENV-001` 백야성 상공 지도형 콘셉트
- `ENV-002` 객잔 내부 구조
- `ENV-003` 북문과 수로
- `ENV-004` 시장 화재 전·후
- `UI-001` 상단전 시야 분위기 보드
- `FX-001` 검대별 궤적과 정지 표현
- `AUD-001` 검관 잠금과 검대 음향을 위한 시각 무드보드

## 6. 세션당 권장 생성량

한 세션에서 완전히 다른 이미지 10장을 만들기보다 다음 방식을 사용한다.

1. 기준 이미지 1종 생성
2. 가장 좋은 방향 1종 선택
3. 구조 수정 2~3회
4. 확정 이미지 1종
5. 기준 문서에 유지·수정 요소 기록

## 7. 승인 상태

| 상태 | 의미 |
|---|---|
| `DRAFT` | 방향 탐색, 다른 작업의 기준으로 사용 금지 |
| `REVISE` | 일부 유지 가능, 수정 필요 |
| `CANONICAL` | 이후 이미지와 3D 제작의 기준 |
| `SUPERSEDED` | 더 최신 기준으로 대체됨 |

## 8. 다음 세션 즉시 실행 항목

```text
1. CA-001 이연 전신 키시트 생성
2. 얼굴·체형·의상·검관 비율 검수
3. 필요 수정 후 CA-001을 CANONICAL 후보로 선정
4. 동일 이연을 유지해 CA-002 검관 구조 시트 생성
5. 두 기준이 확정되면 KF-001 관천협의 108검 생성
```
