# 이연 캐릭터 콘셉트 바이블

> 상태: `CANONICAL DRAFT`  
> 목적: 캐릭터 시트, 키아트, 표정, 전투 포즈, 3D 모델링 기준

## 1. 캐릭터 정의

### 이름

이연

### 연령과 인상

- 기준 연령: 36세
- 동아시아계 남성
- 젊은 미소년도, 노쇠한 고수도 아닌 완성된 현역 해결사
- 실제 나이보다 약간 더 지쳐 보이지만 쇠약해 보이지 않는다.
- 첫인상은 냉정함보다 **상황을 이미 파악한 사람의 여유**에 가깝다.

### 역할

- 천류문 멸문 생존자
- 의뢰를 받고 분쟁을 끝내는 강호의 해결사
- 하단전 파괴로 일반 내공 사용 불가
- 상단전 의념으로 108검을 12개 검대로 지휘
- 검객이라기보다 혼자 이동하는 군진

## 2. 신체 기준

- 키: 약 184cm
- 체형: 긴 팔다리, 넓지만 과장되지 않은 어깨, 마른 듯 보이는 고밀도 근육
- 근육 표현: 갑옷형 근육이나 보디빌더 체형 금지
- 자세: 허리와 목을 곧게 세우며 무게 중심이 낮다.
- 손: 검술가의 굳은살과 잔상처가 있으나 과도한 괴물 손 금지
- 걸음: 느리지 않지만 서두르지 않는다. 검관의 무게 때문에 끌려가는 자세가 아니다.

## 3. 얼굴

### 형태

- 길지 않은 타원형과 각진 턱의 중간
- 높은 광대보다 단단한 턱선과 곧은 콧대
- 눈은 크지 않고 길며, 사람보다 공간과 퇴로를 먼저 보는 시선
- 굵지 않은 일자형 눈썹
- 입술은 얇되 냉혹한 악역처럼 과장하지 않는다.

### 피부와 흔적

- 햇볕과 비바람에 노출된 자연스러운 중간 피부톤
- 턱과 뺨에 하루 이틀 자란 수염 그림자
- 왼쪽 턱선 아래에 짧고 옅은 절상 흉터 하나
- 눈을 가로지르는 대형 흉터, 화상, 문신 금지

### 표정 기본값

- 무표정이 아니라 감정을 통제한 상태
- 위협받을 때 눈을 크게 뜨거나 이를 드러내지 않는다.
- 상대가 거짓말할 때 입꼬리가 아주 미세하게 내려간다.
- 사람을 구한 뒤 안도감을 말로 표현하지 않고 시선을 한 번 확인한다.
- 분노는 얼굴이 아니라 검관의 쇠사슬을 한 번 더 감는 행동으로 드러낸다.

## 4. 머리

- 짙은 검은색
- 어깨에 닿지 않는 중간 길이
- 뒤쪽을 낮고 느슨하게 묶음
- 앞머리 일부가 비와 바람에 풀려 얼굴 옆으로 떨어짐
- 매끈한 선비 상투, 긴 선협 머리, 현대식 언더컷 금지
- 백발이나 오색 머리 금지

## 5. 의상

### 기본 실루엣

- 먹색과 숯색을 중심으로 한 긴 무복
- 무릎 아래까지 내려오는 비대칭 겉옷
- 걸을 때 옷자락이 넓게 펄럭이기보다 무겁게 따라온다.
- 안쪽은 움직임에 맞는 좁은 소매와 바지
- 왼쪽 어깨와 등에는 검관 쇠사슬의 마찰을 받는 가죽 보강대

### 재질

- 비에 젖으면 광택이 살짝 드러나는 두꺼운 면·마 혼방
- 낡았지만 해지지 않은 검은 가죽
- 버클과 고리는 무광 흑철
- 금사 자수, 비단 광택, 황제형 장식 금지

### 색 역할

- 주색: 먹색, 숯색, 젖은 흑갈색
- 보조: 낡은 회갈색 가죽
- 금속: 차가운 회철색
- 작은 기억 표식: 천류문의 탁한 청회색 매듭 하나
- 붉은색은 피나 세력 표식에 남겨 두며 이연 의상 주색으로 사용하지 않는다.

### 신발과 보호구

- 젖은 돌길과 진흙에 맞는 낮은 검은 가죽 장화
- 팔뚝 안쪽에만 얇은 가죽 보호대
- 판금 갑옷, 화려한 견갑, 망토형 어깨 장식 금지

## 6. 무명검

- 108검과 별도로 허리 왼쪽에 한 자루
- 장식 없는 직선형 검
- 검집은 검게 옻칠했으나 오래 사용해 모서리가 닳음
- 코등이는 작고 실용적
- 이연이 직접 뽑는 장면은 드물어야 한다.
- 무명검은 최종 책임을 자기 손으로 질 때 사용한다.

## 7. 상단전 표현

상단전은 마법의 제3안이나 이마 문양으로 표현하지 않는다.

### 평상시

- 외형 변화 없음
- 주변 검의 미세한 방향 정렬로 능력을 암시

### 상단전 시야 활성

- 동공 주변에 매우 얇은 냉회색 반사광
- 얼굴 전체가 발광하지 않음
- 공기 중에 룬이나 마법진이 나타나지 않음
- 검대의 간격과 시선 방향이 정확히 일치

### 과부하 금지

- 매 장면 코피, 눈의 출혈, 비명, 두통 포즈 금지
- 특정 극한 장면에서만 아주 미세한 피로 징후를 사용하며 능력 실패로 연결하지 않는다.

## 8. 기본 포즈

### POSE-A 검관을 끄는 남자

- 몸은 정면에서 15도 틀어짐
- 왼손에 쇠사슬을 느슨하게 잡음
- 오른손은 무명검 근처에 있지만 칼자루를 움켜쥐지 않음
- 뒤쪽에 검관이 낮게 이어짐
- 시선은 카메라가 아니라 길 끝

### POSE-B 미세 명령

- 엄지와 검지로 쇠사슬의 한 고리를 가볍게 튕김
- 얼굴과 상체는 거의 움직이지 않음
- 뒤에서 9검이 같은 각도로 들림

### POSE-C 검교 이동

- 날아가는 검의 평면 또는 코등이를 발판으로 밟음
- 무협 경공처럼 허공에서 다리를 크게 벌리지 않음
- 검들이 다음 발판을 계산해 순차적으로 들어옴

### POSE-D 마지막 한 자루

- 108검은 주변 전장을 고정한 채 멈춤
- 이연만 무명검을 뽑아 적에게 걸어감
- 화려한 자세보다 짧고 무거운 결단

## 9. 표정 시트 권장

1. 기본 관찰
2. 상대의 거짓말을 알아챔
3. 얕은 냉소
4. 계약을 수락함
5. 살려 둘지 결정함
6. 동료의 죽음을 확인함
7. 분노를 통제함
8. 최종 처형 직전

과장된 미소, 광기, 소년 만화식 고함 표정은 사용하지 않는다.

## 10. 캐릭터 이미지 필수 산출물

### CA-001 전신 키시트

- 정면 3/4 전신
- 검관 포함 실루엣
- 무명검과 쇠사슬 가시성
- 중립 배경

### CA-001B 턴어라운드

- 정면 / 측면 / 후면
- 겉옷 길이와 검관 연결 구조 확인
- 장식보다 실제 제작 가능성 우선

### CA-001C 얼굴 시트

- 정면 / 3/4 / 측면
- 기본 표정과 4개 미세 표정
- 흉터 위치 고정

### CA-001D 행동 포즈

- 쇠사슬 명령
- 검교 이동
- 무명검 직접 사용

## 11. 이미지 생성 앵커

다음 문장을 모든 이연 이미지의 공통 기준으로 사용한다.

> 36세의 동아시아계 남성 무협 해결사, 키가 크고 마른 듯 단단한 체격, 각진 턱과 길고 차분한 눈, 낮게 묶은 중간 길이 검은 머리, 옅은 수염 그림자와 왼쪽 턱선의 짧은 흉터, 먹색의 낡고 실용적인 긴 무복, 과도한 장식 없는 흑철과 가죽, 허리의 장식 없는 무명검, 뒤로 거대한 관형 검 수레를 검은 쇠사슬로 끌며 서 있는 완성형 강자, 절제된 자세와 압도적인 통제감

## 12. 금지 변형

- 20대 미소년
- 50~60대 백발 노인
- 근육질 야만전사
- 화려한 황금 갑옷
- 일본 사무라이 또는 닌자
- 장검 여러 자루를 등에 꽂은 흔한 검객
- 손에서 마법 광선을 쏘는 술사
- 허리를 숙이고 검관을 힘겹게 끄는 노동자형 자세
- 웃으며 포즈를 취하는 영웅형 키아트
- 눈 전체가 푸르게 발광하는 초능력자
